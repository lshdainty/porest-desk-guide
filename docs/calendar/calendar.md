# 캘린더

일정을 등록하고 확인합니다. 데스크톱은 **일 · 주 · 월 · 연 · 목록** 다섯 가지로 보고, 모바일(웹 · 앱)은 월 달력 하나로 봅니다. 할 일과 가계부 거래는 캘린더에 나오지 않습니다 — 거래는 [가계부의 달력 보기](../expense/transactions.md#화면-구성)에서 봅니다.

## 화면 구성

### 데스크톱

- 왼쪽 위 **오늘 날짜 칸**을 누르면 오늘로 돌아옵니다. 옆의 **2026년 9월 ▾** 를 누르면 연 · 월을 골라 이동하고, 지금 보는 기간의 **일정 N개**가 함께 보입니다. 그 아래 **‹ ›** 로 이전 · 다음 기간으로 옮깁니다
- 오른쪽 **[● 캘린더]** 로 화면에 보일 캘린더와 공휴일을 고르고([아래](#여러-캘린더-표시--숨기기)), 그 옆 버튼 다섯 개로 보기를 바꿉니다 — **일 · 주 · 월 · 연 · 목록**
- 월 보기에서 **날짜 숫자**를 누르면 그날의 일 보기로 넘어가고, 칸에 다 안 들어가는 일정은 "+N개" 로 묶입니다. 연 보기에서 날짜를 누르면 그날 일 보기로 갑니다
- 토요일은 파랑, 일요일과 공휴일은 빨강으로 표시됩니다

### 모바일(웹 · 앱)

- 맨 위 **‹ 2026년 9월 ›** — 가운데를 누르면 연 · 월을 골라 이동합니다. 오른쪽 칩(보이는 캘린더 수 "N개")으로 표시할 캘린더를 고릅니다
- **날짜를 누르면 그날의 일정** 창이 먼저 뜹니다(공휴일도 함께). 일정을 한 번 더 누르면 상세가 열리고, 창 아래 **[일정 추가]** 로 그 날짜에 새 일정을 만듭니다
- 캘린더 화면에서는 아래 탭 바 가운데 **+** 가 거래가 아니라 **일정 추가**를 엽니다

## 일정 생성

- **데스크톱**: **월 보기**에서 날짜 칸의 **빈 곳을 누르면** 그 날짜로, 여러 날을 **끌어서 고르면** 그 기간으로 "일정 추가" 창이 열립니다(날짜 숫자를 누르면 일 보기로 넘어가니 숫자 말고 빈 곳을 누르세요). 주 · 일 · 연 · 목록 보기에서는 일정을 만들 수 없습니다
- **모바일**: 아래 탭 바의 **+**, 또는 날짜를 누른 뒤 **[일정 추가]**

| 칸 | 설명 |
|---|---|
| **제목** | 꼭 넣어야 합니다(200자까지) — 비우면 "제목을 입력해 주세요" |
| 설명 | 10,000자까지. 상세에서는 **메모**로 보입니다 |
| 캘린더 | 처음엔 **기본 캘린더**. [캘린더 목록](#여러-캘린더-표시--숨기기)에서 숨겨 둔 캘린더는 고를 수 없습니다 |
| 라벨 | [라벨](../settings/calendar.md)을 하나 이상 만들어 두었을 때만 보입니다. "라벨 없음" 으로 둘 수 있습니다 |
| 색상 | 10가지 중 고릅니다 — 다만 화면에 보이는 색은 아래 안내를 보세요 |
| 종일 | 처음엔 켜져 있습니다. 끄면 시작 · 종료에 시각 칸(5분 단위, 처음엔 09:00 ~ 10:00)이 붙습니다 |
| 시작일 · 종료일 | 시작을 종료보다 뒤로 옮기면 종료가 따라 옮겨집니다. 종료가 시작보다 앞이면 "종료일이 시작일보다 빠를 수 없어요" 가 뜨고 저장이 막힙니다. 지난 날짜로 등록하는 건 자유롭습니다 |
| 장소 | 500자까지 |
| 반복 | 반복 없음 · 매일 · 매주 · 매월 · 매년. **끝나는 날을 정하는 칸은 없어** 한 번 반복하면 계속 이어집니다 |
| 알림 | 5분 전 · 15분 전 · 30분 전 · 1시간 전 · 1일 전 — 여러 개를 함께 고를 수 있습니다([일정 알림](#일정-알림)) |

**[저장]** 을 누르면 만들어집니다.

:::info[일정은 라벨 색, 없으면 캘린더 색으로 보여요]
캘린더에 보이는 일정 색은 **라벨을 붙였으면 라벨 색**, 없으면 **그 일정이 든 캘린더의 색**입니다. 일정 폼의 **색상**은 지금 화면 표시에 쓰이지 않으니, 일정마다 색을 달리하고 싶다면 라벨을 쓰세요. 캘린더를 바꾸면 색상 칸도 그 캘린더 색으로 바뀝니다.
:::

## 일정 확인 · 수정

일정을 누르면 상세가 열립니다(데스크톱은 그 자리에 뜨는 카드, 모바일은 아래에서 올라오는 창).

- 맨 위에 **캘린더 이름**과 **D-day**(오늘이면 D-DAY, 지난 일정은 "N일 지남"), 제목
- **시작 → 종료** — 날짜와 시각, 가운데에 걸리는 시간(예: "1시간 30분") 또는 "종일"
- **장소 · 라벨**(있을 때), **반복**, **알림**(있을 때), 그리고 설명을 담은 **메모**
- 아래 **[일정 삭제] · [일정 수정]** — 공휴일에는 없습니다

**[일정 수정]** 을 누르면 추가할 때와 같은 폼이 "일정 수정" 으로 열립니다. 수정 폼 아래에도 **[삭제]** 가 있습니다.

:::warning[반복 일정은 "전체"를 고치고 지웁니다]
반복 일정은 회차마다 따로 있는 게 아니라 **일정 하나가 반복해서 보이는 것**입니다. 그래서 어느 회차를 열어 고치든 지우든 **반복 전체에 적용**되고, "이번 회차만" 고르는 선택지는 없습니다.

특히 **뒤쪽 회차를 열어 [저장]하면, 반복의 시작일이 그 회차 날짜로 옮겨져 그 앞 회차들이 캘린더에서 사라집니다** — 아무 칸도 바꾸지 않고 저장만 해도 그렇습니다. 반복 일정을 고칠 때는 **첫 회차**를 열어 고치세요.
:::

## 일정 삭제

상세의 **[일정 삭제]**(또는 수정 폼의 [삭제])를 누르면 **"○○" 일정을 삭제할까요? 이 작업은 되돌릴 수 없습니다.** 확인 창이 뜨고, **[삭제]** 를 누르면 지워집니다.

## 공휴일 표시

대한민국 공휴일은 **매일 낮 12시**(한국 시간)에 자동으로 갱신되고, 빨간 일정으로 표시됩니다. 공휴일도 누르면 상세가 열리지만 고치거나 지울 수는 없습니다. 보고 싶지 않으면 [캘린더 목록](#여러-캘린더-표시--숨기기)의 **공휴일**을 끄세요.

## 여러 캘린더 표시 · 숨기기

데스크톱은 상단의 **[● 캘린더]**, 모바일은 오른쪽 칩을 누르면 목록이 열립니다.

- **캘린더** — 내가 만든 캘린더와 [공유받은 캘린더](../settings/calendar.md#캘린더-공유)가 나오고, 하나씩 눌러 화면에 보일지 켜고 끕니다. 이 선택은 계정에 저장되어 다른 기기에도 똑같이 적용됩니다
- **기타 소스** — **공휴일** 하나입니다
- 맨 아래 **캘린더 관리 · 공유 설정** 으로 [설정 → 캘린더 관리·공유](../settings/calendar.md#캘린더-공유)에 갑니다

![캘린더 목록 드롭다운 — "내 캘린더(기본)"만 체크박스 없이 항상 켜져 있습니다](/img/screens/calendar-visibility-dropdown.png)

:::info[기본 캘린더는 숨길 수 없어요]
**기본 캘린더** 줄에는 켜고 끄는 칸 대신 늘 켜진 표시와 **기본** 표가 붙어 있습니다("기본 캘린더는 숨길 수 없습니다"). 새 일정이 처음 들어가는 자리라, 숨기면 방금 만든 일정이 곧바로 안 보이기 때문입니다. 숨겨 둔 캘린더는 일정 추가 창의 캘린더 목록에도 나오지 않습니다.
:::

## 일정 알림

일정에 넣은 알림은 그 시각이 되면 [알림 목록](../settings/notifications.md)(종 아이콘)에 **"(일정 제목) 알림"** 으로 쌓입니다. 휴대폰 푸시나 이메일로는 오지 않습니다.

- 알림 시각은 **일정을 만든 사람의 [기준 지역](../settings/display.md#기준-지역)** 으로 계산합니다(1분 간격으로 확인)
- 알림은 **일정을 만든 사람에게만** 갑니다 — 공유 캘린더의 다른 멤버에게는 가지 않습니다
- **반복 일정은 첫 회차에만** 알림이 옵니다. 다음 회차부터는 오지 않습니다
- [알림 설정](../settings/notifications.md)에서 **일정 알림**을 끄면 오지 않습니다

## 라벨과 공유

일정에 붙이는 라벨은 [설정 → 캘린더 라벨](../settings/calendar.md)에서, 캘린더를 새로 만들고 다른 사람과 함께 쓰는 건 [설정 → 캘린더 관리·공유](../settings/calendar.md#캘린더-공유)에서 합니다 — 캘린더 화면에서는 관리하지 않습니다.

공유 캘린더에서 할 수 있는 일은 권한마다 다릅니다.

| 권한 | 일정 보기 | 일정 만들기 | 남의 일정 고치기 · 지우기 | 내가 만든 일정 고치기 · 지우기 | 멤버 · 캘린더 관리 |
|---|:---:|:---:|:---:|:---:|:---:|
| 소유자 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 편집 가능 | ✓ | ✓ | ✓ | ✓ | — |
| 읽기 전용 | ✓ | — | — | ✓ | — |

읽기 전용 멤버에게도 [일정 수정] · [일정 삭제] 버튼은 보이지만, 남의 일정에서 누르면 막힙니다.
