# 캘린더

일정을 등록하고 월 · 주 · 일 단위로 확인합니다.

## 화면 구성

- **보기 전환**: 월 · 주 · 일 · 연 · 목록 보기 중 선택
- **오늘로 이동**: 언제든 오늘 날짜로 바로 이동하는 버튼
- **표시 항목 토글**: 지출 내역 · 공휴일을 캘린더 위에 같이 표시할지 켜고 끕니다

![캘린더 월간 보기 — 등록한 일정과 공휴일(추석)이 함께 표시됩니다](/img/screens/calendar-month.png)

![모바일 화면 — 하단 탭 가운데 + 버튼으로 바로 일정을 추가할 수 있습니다](/img/screens/mobile-calendar.png)

## 일정 생성

1. 날짜(또는 시간대) 칸을 누르고 **[일정 추가]** 를 누릅니다
2. **제목**, 필요하면 **설명 · 장소**를 입력합니다
3. **캘린더**를 고릅니다 — 고르지 않으면 자동으로 **내 캘린더(기본 캘린더)** 에 들어갑니다
4. **색상(라벨)**을 골라 종류별로 구분합니다
5. **종일** 여부를 정하고 **시작일 · 종료일**을 입력합니다
6. 필요하면 **반복**(매일 · 매주 · 매월 · 매년) 과 **알림**(5분 전 · 15분 전 · 30분 전 · 1시간 전 · 1일 전) 을 설정합니다
7. **[저장]**

![일정 추가 — 제목·캘린더·색상 라벨·종일 여부·기간·장소·반복·알림을 한 화면에서 설정합니다](/img/screens/calendar-add-form.png)

:::warning[종료일은 시작일보다 빠를 수 없어요]
시작일 · 종료일을 뒤바꿔 저장하려 하면 막힙니다. 다만 지난 날짜로 일정을 등록하는 것 자체는 자유롭게 할 수 있습니다.
:::

## 일정 확인 · 수정

날짜를 누르면 그날의 일정이 목록으로 모여 보이고, 일정을 누르면 상세 카드가 펼쳐집니다. **[일정 수정]** 을 누르면 추가할 때와 같은 폼이 열려 제목 · 날짜 · 시간 · 라벨 · 반복 · 알림을 모두 고칠 수 있습니다.

![일정 상세 카드 — 아래쪽에 일정 삭제·일정 수정 버튼이 있습니다](/img/screens/calendar-detail-actions.png)

## 일정 삭제

상세 카드의 **[일정 삭제]** 를 누르고 확인 창에서 **[삭제]** 를 누릅니다.

![일정 삭제 확인 — 삭제하면 되돌릴 수 없습니다](/img/screens/calendar-delete-confirm.png)

:::danger[되돌릴 수 없습니다]
"이 작업은 되돌릴 수 없습니다"라는 문구 그대로, 삭제한 일정은 복구할 방법이 없습니다. 반복 일정도 삭제 확인 창은 똑같이 뜨고, "이번 일정만" 또는 "전체 반복 일정" 중 골라 지우는 선택지는 따로 없습니다.
:::

## 공휴일 표시

대한민국 공휴일은 **매일 낮 12시**에 자동으로 갱신됩니다(올해와 내년 것을 함께 동기화). 사용자의 [표시 지역 설정](../settings/display.md)과 무관하게 서버 기준 날짜로 갱신되지만, 실제 화면에는 각자의 달력 기준 날짜에 정확히 표시됩니다.

## 일정 알림

일정 리마인더는 캘린더 갱신과 달리 **사용자 개인의 시간대**를 정확히 기준으로 도래 시점을 계산합니다(1분 간격으로 확인). 여행 중 다른 나라에 있어도 그 사람의 현지 시각 기준으로 알림이 옵니다.

## 라벨과 공유

일정에 붙이는 색상 라벨은 [설정 → 캘린더 라벨 · 공유](../settings/calendar.md)에서 미리 만들어 둡니다. 캘린더 자체를 다른 사람과 공유하는 것도 이 설정 화면에서 관리합니다 — **캘린더 화면이 아니라 항상 설정에서** 공유 · 라벨을 관리하도록 되어 있습니다.

초대코드로 다른 사람의 캘린더에 참여하면 기본 권한은 **편집 가능**입니다(일정을 만들고 지울 수 있음) — 소유자가 나중에 "읽기 전용"으로 낮출 수 있습니다. 읽기 전용으로 들어간 사람은 일정 등록 · 수정 버튼이 화면에 보이더라도 실제로는 막힙니다.

:::info[공유 캘린더 멤버 목록]
공유 캘린더의 멤버 목록을 열어보면, 읽기 전용으로 참여한 사람도 다른 멤버들의 이메일을 볼 수 있습니다.
:::

캘린더 자체를 삭제하면 그 안의 일정은 지워지지 않고 소유자의 기본 캘린더로 옮겨지며, 공유받던 사람들은 접근이 끊깁니다.
