# 카드 혜택

내가 가진 카드가 아니어도, 여러 카드사의 혜택을 미리 찾아볼 수 있는 라이브러리입니다.

## 화면 구성

- **검색**: 카드 이름으로 찾기
- **필터**: 카드 종류, 받을 수 있는 혜택 종류로 좁히기
- **단종 카드 포함**: 지금은 새로 발급되지 않는 카드도 같이 볼지 켜고 끕니다

![카드 혜택 라이브러리 — 6,767건의 카드 정보를 종류·혜택별로 필터링](/img/screens/card-benefit-library.png)

## 카드 상세 보기

카드를 누르면 연회비, 실적 조건, 구체적인 혜택 내용을 모달로 볼 수 있습니다.

:::info["카드 혜택 추천"은 Porest Pro 기능입니다]
라이브러리를 검색 · 필터로 직접 둘러보는 건 Free에서도 그대로 됩니다. 다만 Free · Pro 요금 비교표에는 이와 별개로 "카드 혜택 추천"이 Pro 전용으로 표시되어 있습니다 — 내 소비 패턴에 맞춰 카드를 추천해주는 기능으로 보이며, [구독](../subscription/subscription.md)이 있어야 열립니다.
:::
