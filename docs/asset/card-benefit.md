# 카드 혜택

내가 가진 카드가 아니어도, 여러 카드사의 신용 · 체크카드 혜택을 찾아보고 비교할 수 있는 라이브러리입니다.

## 들어가는 곳

- **데스크톱**: 왼쪽 메뉴의 **카드 혜택**
- **모바일 · 앱**: 아래 탭바의 **전체** → 일상 → **카드 혜택**("신용·체크 카드 검색")

- **검색** — "카드명, 발급사로 검색" 창에 카드 이름이나 **카드사 이름**의 일부를 넣으면 바로 좁혀집니다. 오른쪽 ✕ 로 지웁니다.
- **필터 두 줄**
  - 카드 종류: **전체 · 신용 · 체크**
  - 혜택: **혜택 전체 · 할인 · 적립 · 캐시백 · 마일리지**
- **총 N건** — 지금 필터에 맞는 카드 수
- **단종 카드 포함**(기본 꺼짐) — 켜면 지금은 새로 발급되지 않는 카드도 함께 보여 줍니다. 단종 카드는 흐리게 "단종" 표시가 붙고 목록 뒤쪽에 옵니다.

카드마다 신용/체크, **연회비**(금액 · 무료 · 정보 없음)와 **실적 조건**("실적 N원/월" 또는 "실적 무관")이 보입니다. 데스크톱은 한 쪽에 60장씩 **[이전] · [다음]** 으로 넘기고, 모바일은 내리면 이어서 불러옵니다. 맞는 카드가 없으면 "결과가 없어요 · 다른 검색어나 필터를 시도해보세요" 가 나옵니다.

:::info[혜택 필터는 카드의 "대표 혜택"으로 거릅니다]
카드마다 **대표 혜택 유형이 하나**(할인 · 적립 · 마일리지)로 정해져 있고, 필터는 그것만 봅니다. 할인 카드에 적립 혜택이 조금 딸려 있어도 **적립** 필터에는 나오지 않습니다. 또 카드 정보에서 적립과 캐시백을 구분하지 않아, **적립**과 **캐시백** 필터는 같은 카드들을 보여 줍니다.
:::

## 카드 상세 보기

카드를 누르면 **카드 상세** 창이 열립니다.

- 맨 위 카드 그림
- **연회비**(국내전용 금액 · 무료 · 정보 없음)와 **전월 실적**(N원 이상 · 실적 무관)
- **주요 혜택 태그** 칩
- **혜택 상세 · N건** — 분류 · 혜택 값 · 조건이 한 줄씩 나오고, 누르면 자세한 내용이 펼쳐집니다. **[모두 펼치기] / [모두 접기]** 로 한꺼번에 열고 닫습니다. 등록된 혜택이 없으면 "등록된 혜택이 없어요"
- 아래 **[닫기]**

## 여기서 할 수 없는 것

- **추천**이나 "내가 가진 카드" 표시는 없습니다 — 찾아보기 전용입니다.
- 이 화면에서 바로 카드를 등록하는 버튼은 없습니다. 카드는 [설정 → 계좌 · 카드 관리](../settings/account-card.md#카드-생성)에서 등록하고, 그때 **같은 카드 상품 목록**에서 고릅니다. 등록할 때 고른 상품의 **전월 실적 조건**이 [카드 상세](./card.md)의 실적 표시 기준이 됩니다.
