# 예산

한도를 정해두고 이번 달 지출 페이스를 관리합니다.

## 화면 구성

- **진행률**: 전체 예산과 카테고리별 예산의 사용률
- **지출 페이스**: 지금까지의 일평균 지출과, 남은 예산 안에서 하루에 얼마씩 써도 되는지(권장 일지출)
- **준수율 추이**: 예산을 얼마나 잘 지켜왔는지 지난 기간과 비교

## 한도는 어떻게 정해지나요

**전체 예산을 정해뒀다면 카테고리별 예산은 무시되고 전체 예산 하나만 한도로 쓰입니다.** 전체 예산이 없을 때만 카테고리별 예산의 합이 한도가 됩니다(전체 · 카테고리를 둘 다 더해서 한도로 쓰지 않습니다 — 중복 계산을 막기 위해서입니다).

:::warning[이행률이 100%를 훌쩍 넘어 보인다면]
분자(지출 합계)는 항상 **그 달의 전체 지출**입니다. 카테고리별 예산만 몇 개 잡아뒀다면, 그 카테고리가 아닌 지출까지 분자에 포함되어 이행률이 100%를 넘게 나올 수 있습니다 — 오류가 아니라, 예산을 안 잡은 지출도 실제로는 쓰고 있다는 뜻입니다. 전체 지출을 정확히 관리하고 싶다면 전체 예산을 하나 정해두는 걸 권장합니다.
:::

이행률 계산에서 **아직 날짜가 되지 않은 거래**(반복거래를 미리 만들어 둔 미래분 등)는 빠지고, **환불**(수입으로 들어온 환불액)은 원래 지출에서 상계되어 빠집니다. 퍼센트는 소수점 첫째 자리(0.1%)까지 반올림합니다.

## 월 이동

화살표로 이전 · 다음 달의 예산 현황을 확인합니다. **예산 금액 자체를 새로 정하거나 고치는 건 여기가 아니라 [설정 → 예산 설정](../settings/budget.md)에서 합니다** — 예산 화면은 진행 상황을 "보는" 화면이고, 한도를 "정하는" 것은 설정의 몫으로 나뉘어 있습니다.
