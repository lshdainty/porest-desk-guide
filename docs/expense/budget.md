# 예산

한도를 정해두고 이번 달 지출 페이스를 관리합니다. 예산 금액을 **정하는** 곳은 [설정 → 예산 설정](../settings/budget.md)이고, 이 화면은 진행 상황을 **보는** 곳입니다 — 오른쪽 위 **[⚙ 설정]** 을 누르면 설정으로 바로 갑니다.

## 화면 구성

- **○월 전체 상한** — 이번 달 쓴 돈 / 전체 상한과 막대, 아래에 사용률과 **남은 예산**(넘었으면 "한도 OOO원 초과"). 그 아래 **전체 상한 · 카테고리 할당 · 할당 가능** 세 칸이 있고, 카테고리 한도 합이 전체 상한보다 크면 "카테고리 한도 합이 전체 상한을 OOO원 초과했어요" 경고가 붙습니다. 전체 상한을 아직 정하지 않았다면 그 안내와 함께 지금 카테고리 한도 합계가 대신 보입니다.
- **지출 페이스** — 한도 대비 사용률과 **달이 지나간 비율**을 한 막대에 겹쳐 보여 줍니다("이번 달 53% 경과 ↑"). 사용률이 지난 날 비율보다 5%p 넘게 앞서면 **빠른 속도**, 아니면 **정상 속도**입니다. 아래에 두 숫자가 있습니다.
  - **일평균 지출** — 지금까지 쓴 돈 ÷ 오늘까지 지난 날수(오늘 포함)
  - **남은 일 권장 지출** — 남은 예산 ÷ 오늘을 뺀 남은 날수. 예산을 이미 넘었으면 0원
- **예산 현황** — 한도를 넘은 카테고리 수(**초과**)와 여유 있는 카테고리 수(**여유**)
- **카테고리별 예산** — 카테고리마다 쓴 돈 / 한도, 남은 예산(또는 초과액)과 막대. 비어 있으면 "카테고리별 예산이 없어요" 와 **예산 설정하러 가기 →**
- **최근 6개월 예산 이행률** — **이번 달까지 6개월** 동안 달마다 한도 대비 얼마를 썼는지 막대로 보여 줍니다(위에서 고른 달과 상관없이 늘 최근 6개월). 100%를 넘은 달은 빨간색, 예산을 정하지 않은 달은 0%입니다.

막대 색은 [알림 설정](../settings/notifications.md)의 **예산 알림 임계값**(기본 85%)을 넘으면 경고색, 100%를 넘으면 빨간색으로 바뀝니다.

화면의 퍼센트는 정수로 반올림해 보여 줍니다. 이행률 막대에 마우스를 올리거나 누르면 "한도 대비 OO.O%" 처럼 소수점 첫째 자리까지 볼 수 있습니다.

## 월 이동

화살표로 이전 · 다음 달로 옮기거나, 가운데 **달 이름**을 눌러 원하는 달을 바로 고릅니다. 지난달이나 다음 달을 보면 지출 페이스는 그 달이 다 지난 것으로 계산합니다.

:::info[예산은 달마다 따로입니다]
예산은 달별로 저장되고 **다음 달로 저절로 이어지지 않습니다.** 새 달이 되면 [설정 → 예산 설정](../settings/budget.md)에서 **[지난달 복사]** 를 눌러 한도를 가져오세요.
:::

## 한도는 어떻게 정해지나요

**전체 상한을 정해뒀다면 카테고리별 예산은 무시되고 전체 상한 하나만 한도로 쓰입니다.** 전체 상한이 없을 때만 카테고리별 예산의 합이 한도가 됩니다 — 둘을 더해서 쓰면 같은 지출을 두 번 세게 되기 때문입니다.

:::warning[이행률이 100%를 훌쩍 넘어 보인다면]
분자(쓴 돈)는 항상 **그 달의 전체 지출**입니다. 카테고리별 예산만 몇 개 잡아뒀다면, 그 카테고리가 아닌 지출까지 분자에 들어가 이행률이 100%를 넘게 나올 수 있습니다 — 오류가 아니라, 예산을 안 잡은 지출도 실제로 쓰고 있다는 뜻입니다. 전체 지출을 관리하려면 전체 상한을 하나 정해두세요.
:::

## 무엇이 지출로 잡히나요

예산과 [통계](./stats.md)는 같은 규칙으로 지출을 셉니다.

| 이런 거래는 | 예산 · 통계에서 |
|---|---|
| 할부 | **산 날짜의 달에 전액**이 잡힙니다(카드 청구는 달마다 나뉘어도) |
| 세부 카테고리 지출 | 그 **대분류** 예산에 더해집니다 |
| 나눠 적은(분할) 거래 | 나눈 카테고리별로 셉니다 |
| [환불](./transactions.md#환불)로 표시한 거래 | 원래 거래 날짜의 달에서 **통째로 빠집니다** |
| 카드를 등록할 때 적은 이전 미결제 사용액 | 빠집니다 — 카드 등록 전에 이미 쓴 돈이라서 |
| 결제가 끝난 회차에 뒤늦게 적은 카드 거래("기록만") | **그대로 들어갑니다** — 쓴 돈은 쓴 돈이라서 |
| 이체 원금 · 수수료, 카드 대금 결제 | 지출이 아니라 **빠집니다** |
| 대출을 갚는 이체의 **이자** | 미분류 지출로 잡혀 **전체 상한에만** 들어갑니다 |
| 주식 매도 손실 · 이익 | 손실은 미분류 지출, 이익은 수입으로 잡힙니다 |
| 아직 날짜가 오지 않은 거래 | 빠집니다 — 날짜가 되면 들어갑니다 |

화면별로 금액을 가리고 싶다면 [금액 가리기](../settings/account.md#금액-가리기)에서 예산 요약 · 소비 속도 · 상태 · 카테고리별 예산 · 준수율 카드를 각각 고를 수 있습니다(금액 가리기 화면에서는 "지출 페이스" 를 **소비 속도**, "이행률" 을 **준수율**이라고 부릅니다).
