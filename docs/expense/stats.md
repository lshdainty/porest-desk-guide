# 통계

기록한 거래를 여러 각도로 모아 봅니다.

## 화면 구성

- **카테고리별**: 이번 기간 지출이 어느 카테고리에 몰렸는지 비중으로 확인, 가장 많이 쓴 가맹점 TOP 5, 요일 · 시간대별 지출 패턴(색이 진할수록 지출이 많은 시간대)
- **트렌드**: 시간에 따라 수입 · 지출이 어떻게 변해왔는지
- **기간 비교**: 이번 달과 지난달처럼 두 기간을 나란히 비교

![통계 · 카테고리별 화면 — 카테고리 비중, 가맹점 TOP 5, 요일·시간대 지출 패턴](/img/screens/stats.png)

## 기간 선택

월 · 분기 · 연 단위로 고르거나, 원하는 기간을 직접 지정할 수 있습니다.

:::tip[예산 화면과 숫자가 같아야 정상입니다]
통계의 요약 · 추이 그래프와 [예산](./budget.md) 이행률은 같은 규칙(아직 오지 않은 반복거래 예정분 제외, 환불 상계)으로 계산됩니다. 두 화면의 지출 합계가 서로 다르게 보인다면 새로고침해보세요.

다만 거래를 저장할 때 뜨는 **"예산 90% 사용" 알림**만은 계산 경로가 달라, 아직 실행되지 않은 반복거래 예정분까지 포함될 수 있어 이행률 화면과 정확히 일치하지 않을 수 있습니다.
:::
