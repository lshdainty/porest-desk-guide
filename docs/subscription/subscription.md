# Porest Pro 구독

기본 기능은 무료로 쓸 수 있고, **Porest Pro**를 구독하면 증권 연동 관련 기능이 열립니다.

## 어디서 구독하나요?

**설정 → 계정**에서 Free와 Pro의 기능 차이를 비교하고 구독 · 해지할 수 있습니다. 구독 관리 화면과 "내 권한 확인" 화면 자체는 구독이 없어도 항상 열립니다.

## 구독하면 열리는 것

- [증권 연동](../stocks/securities-link.md) — 토스 · 나무증권 계정을 연결해 보유 종목을 Desk 안에서 확인

구독이 없는 상태로 증권 관련 화면 · API에 접근하면 이용할 수 없다는 안내가 뜹니다.

:::warning[해지하면 남은 기간과 상관없이 바로 막힙니다]
화면에 "이용 기간 ~ 9월 30일까지"처럼 남은 기간이 표시되어 있어도, **해지 버튼을 누르는 즉시** 증권 관련 기능이 막힙니다. 이번 달 요금을 이미 냈으니 월말까지는 쓸 수 있는 방식이 아니니 주의하세요.
:::

## 자동 갱신

**자동 갱신**을 켜두면 만료일에 자동으로 기간이 연장됩니다. 꺼두면 만료일 자정에 자동으로 이용이 종료(만료 처리)됩니다.

## 해지해도 연동 정보는 남아 있어요

Pro를 해지해도 그동안 등록해둔 토스 · 나무증권 연동 키는 삭제되지 않고 그대로 보관됩니다. 나중에 다시 구독하면 API 키를 처음부터 다시 입력할 필요가 없습니다.
