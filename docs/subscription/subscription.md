# Porest Pro 구독

기본 기능은 무료(Free)로 쓸 수 있고, **Porest Pro**를 구독하면 몇 가지 제한이 풀리고 기능이 추가로 열립니다.

## 어디서 구독하나요?

**설정 → 계정 → 구독 · 결제**의 **[Pro 시작]** 을 누르면 요금 비교 화면이 열립니다. Free 상태에서도 이 화면 자체는 항상 열어볼 수 있습니다.

## Free와 Pro의 차이

| 기능 | Free | Pro |
|---|:---:|:---:|
| 가계부 · 자산 관리 | ✓ | ✓ |
| 예산 · 저축 목표 · 캘린더 | ✓ | ✓ |
| 월 거래 기록 | **100건** | 무제한 |
| [증권 연동](../stocks/securities-link.md) — 실시간 시세 · 종목 검색 · 관심종목 | — | ✓ |
| [CSV · Excel 가져오기 / 내보내기](../settings/data-transfer.md) | — | ✓ |
| 다중 캘린더 공유 | — | ✓ |
| 카드 혜택 추천 | — | ✓ |

:::danger[가계부를 한 달에 100건 넘게 쓰면]
Free 플랜은 **월 거래 기록이 100건으로 제한**됩니다. 카드 여러 장을 자동 반영으로 쓰거나 거래가 잦은 달에는 이 한도에 걸릴 수 있으니, 기록량이 많다면 Pro 구독을 고려하세요.
:::

## 해지하면 남은 기간과 상관없이 바로 막힙니다

:::warning[남은 기간이 표시되어 있어도 해지 즉시 막힙니다]
화면에 "이용 기간 ~ 9월 30일까지"처럼 남은 기간이 표시되어 있어도, **해지 버튼을 누르는 즉시** Pro 전용 기능이 막힙니다. 이번 달 요금을 이미 냈으니 월말까지는 쓸 수 있는 방식이 아니니 주의하세요.
:::

## 자동 갱신

**자동 갱신**을 켜두면 만료일에 자동으로 기간이 연장됩니다. 꺼두면 만료일 자정에 자동으로 이용이 종료(만료 처리)됩니다.

## 해지해도 연동 정보는 남아 있어요

Pro를 해지해도 그동안 등록해둔 토스 · 나무증권 연동 키는 삭제되지 않고 그대로 보관됩니다. 나중에 다시 구독하면 API 키를 처음부터 다시 입력할 필요가 없습니다.
