# Porest Pro 구독

기본 기능은 무료(Free)로 쓸 수 있고, **Porest Pro**를 구독하면 **증권** 기능 — 증권사 연동 · 실시간 시세 · 투자 자산의 실시간 금액 — 이 열립니다. Pro가 더 주는 건 이것 하나입니다.

## 어디서 구독하나요?

**설정 → 계정**의 **Porest Pro** 줄(Free면 오른쪽에 "Pro 시작")을 누르면 **구독 관리** 창이 열립니다. Free일 때 증권 화면에 뜨는 "증권 구독이 필요해요" 안내의 **[구독 보기]** 를 눌러도 이 계정 화면으로 옵니다.

## 구독 관리 창

위에서부터:

- **지금 플랜** — Free면 "Free 플랜 이용 중 · 증권 연동 · 실시간 시세가 잠겨 있어요", Pro면 "Porest Pro 이용 중 · 다음 결제 2026-10-11 · 9,900원" 처럼 나옵니다. 해지한 뒤 남은 기간에는 "다음 결제" 대신 **"2026-10-11까지 이용"** 이 보입니다
- **증권 투자는 Pro 전용이에요** — 실시간 시세 · 호가, 국내외 종목 검색, 관심종목, 보유 손익
- **월간 / 연간 17%↓** — 요금 표시를 바꿉니다. 월간은 **9,900원 / 월**, 연간은 **99,000원 / 년**(월 8,250원 꼴)
- **Free · Pro 카드** — 지금 쓰는 쪽에 "현재 플랜" 표시
- **기능 비교** 표(아래)
- 맨 아래 버튼 — Free면 **[닫기] [Pro 시작하기]**, Pro면 **[닫기] [구독 해지]**

:::info[지금은 결제 없이 한 달 단위로 시작돼요]
아직 결제 수단을 받는 단계가 붙어 있지 않아, **[Pro 시작하기]** 를 누르면 곧바로 "Porest Pro 구독이 시작되었어요" 가 뜨고 Pro가 열립니다. 월간 · 연간 중 어느 쪽을 골라 두어도 **한 달짜리**로 시작되고, 기간이 끝나면 한 달씩 자동으로 이어집니다(자동 갱신을 따로 켜고 끄는 스위치는 없습니다 — 멈추려면 해지하세요).
:::

## Free와 Pro의 차이

화면의 기능 비교표에 있는 세 줄이 전부입니다.

| 기능 | Free | Pro |
|---|:---:|:---:|
| 가계부 · 자산 관리 | ✓ | ✓ |
| 예산 · 저축 목표 · 캘린더 | ✓ | ✓ |
| [증권사 연동](../stocks/securities-link.md) · 실시간 시세 · [자산 실시간 금액](../asset/overview.md#투자-자산은-지금-금액과-추이-그래프가-따로-움직입니다) | — | ✓ |

Pro인지를 확인하는 자리는 다음뿐입니다.

- **증권 화면** — Free면 잠겨 있고, 왼쪽 메뉴 · 전체 메뉴에 증권이 보이지 않습니다
- **설정 → 계정의 증권 데이터 연동** 줄 — Pro일 때만 나옵니다
- **투자 자산의 실시간 금액**과, 매일 오후 4시에 추이 그래프에 찍히는 **평가 금액 기록**
- **[desk 이용 해지](../settings/account.md#pro-구독이-남아-있으면-해지할-수-없어요)** — Pro 기간이 남아 있으면 해지할 수 없습니다

:::info[Free에는 기록 건수 · 내보내기 제한이 없습니다]
거래를 몇 건 쓰든, [데이터를 내보내든](../settings/data-transfer.md), [캘린더를 몇 개 만들어 공유하든](../settings/calendar.md), [카드 혜택](../asset/card-benefit.md)을 보든 구독과 무관합니다.
:::

## 해지

1. 구독 관리 창의 **[구독 해지]** 를 누릅니다
2. "해지하면 2026-10-11부터 Free 플랜으로 전환되고 증권 탭이 잠겨요. 그 전까지는 Pro 기능을 계속 쓸 수 있어요." 에서 **[구독 해지]**(그만두려면 **[유지하기]**)
3. "구독을 해지했어요" 가 뜹니다

해지해도 **이미 시작한 기간이 끝날 때까지는 Pro가 그대로** 열려 있고, 그날부터 Free로 바뀝니다. 해지는 자동으로 이어지는 것만 멈추는 것입니다.

:::warning[해지는 되돌릴 수 없어요]
해지를 취소하거나 자동 갱신을 다시 켜는 버튼은 없습니다. 남은 기간 동안 구독 관리 창에는 [구독 해지]만 보이고, 기간이 끝나 Free가 된 뒤에 **[Pro 시작하기]** 로 다시 시작할 수 있습니다.
:::

## Free로 돌아가면 달라지는 것

- 증권 화면이 잠기고 메뉴에서 사라집니다
- 투자 자산은 실시간 금액 대신 **마지막으로 기록된 금액**에 머물고, 추이 그래프에 새 점이 찍히지 않습니다
- 설정의 **증권 데이터 연동** 줄이 사라집니다

그동안 등록해 둔 **토스 · 나무증권 연동 키는 지워지지 않고 그대로 보관**됩니다. 다시 구독하면 키를 처음부터 입력할 필요 없이 바로 이어집니다.
