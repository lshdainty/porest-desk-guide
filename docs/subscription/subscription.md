# Porest Pro 구독

기본 기능은 무료(Free)로 쓸 수 있고, **Porest Pro**를 구독하면 증권사 연동 기능이 추가로 열립니다.

## 어디서 구독하나요?

**설정 → 계정 → 구독 · 결제**의 **[Pro 시작]** 을 누르면 요금 비교 화면이 열립니다. Free 상태에서도 이 화면 자체는 항상 열어볼 수 있습니다.

## Free와 Pro의 차이

| 기능 | Free | Pro |
|---|:---:|:---:|
| 가계부 · 자산 관리 | ✓ | ✓ |
| 예산 · 저축 목표 · 캘린더 | ✓ | ✓ |
| [증권 연동](../stocks/securities-link.md) · 실시간 시세 | — | ✓ |

## 해지해도 남은 기간까지는 그대로 쓸 수 있습니다

:::info[해지하면 자동 갱신만 꺼집니다]
화면에 "이용 기간 ~ 9월 30일까지"처럼 남은 기간이 표시되어 있으면, **해지 버튼을 눌러도 그날까지는 Pro 기능이 그대로 열려 있습니다.** 해지로 꺼지는 건 자동 갱신이라, 이미 낸 이번 기간 요금만큼 끝까지 쓰고 만료일에 Free로 돌아갑니다.
:::

## 자동 갱신

**자동 갱신**을 켜두면 만료일에 자동으로 기간이 연장됩니다. 꺼두면 만료일 자정에 자동으로 이용이 종료(만료 처리)됩니다.

## 해지해도 연동 정보는 남아 있어요

Pro를 해지해도 그동안 등록해둔 토스 · 나무증권 연동 키는 삭제되지 않고 그대로 보관됩니다. 나중에 다시 구독하면 API 키를 처음부터 다시 입력할 필요가 없습니다.
