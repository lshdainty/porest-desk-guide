# 증권 화면

연동한 증권사의 보유 종목과 시세를 보는 화면입니다. **데스크톱은 왼쪽 메뉴의 증권**, 모바일은 **전체 → 돈 관리 → 증권**으로 들어갑니다.

연동한 증권사에 따라 보이는 내용이 다릅니다 — 화면을 다르게 설계해서가 아니라, **두 증권사가 공개한 API가 서로 다른 정보를 주기 때문**입니다. 둘 다 연결했다면 데스크톱은 왼쪽 메뉴 **증권** 아래에서, 모바일은 화면 맨 위 탭에서 증권사를 고릅니다.

:::info[여기서 주문은 되지 않아요]
증권 화면은 **보기 전용**입니다. 토스증권 종목 상세에 **[매도] · [매수]** 버튼이 있지만, 눌러도 "○○ 매수 주문 — Open API 연동 시 동작" 안내만 뜨고 주문은 나가지 않습니다. 시세도 증권사 Open API가 주는 **지연 시세**입니다.
:::

## 공통 구성

- **맨 위 요약** — 내 투자 평가금액과 보유 종목 수, 환율 등
- **목록** — **보유 N** · **관심 N** 탭. 오른쪽 위 **종목 검색**으로 "종목명 · 티커로 검색 (예: 삼성전자, NVDA)" 하고, 별표를 눌러 관심 종목에 담습니다
- **관심 그룹** — 관심 종목을 그룹으로 나눌 수 있습니다(**그룹 추가 · 그룹 이름 변경 · 그룹 삭제**). 그룹을 지우면 "그룹과 담긴 종목이 함께 삭제됩니다" 를 한 번 묻습니다. 관심 목록은 증권사와 상관없이 하나로 저장되어, 토스 · 나무 화면에 똑같이 나옵니다
- **전체 포트폴리오** — 종목별 구성 비중과 통화별 합계
- **종목 상세** — 종목을 누르면 데스크톱은 오른쪽, 모바일은 아래에서 올라오는 창으로 열립니다. 종목명 · 티커 · 시장, 현재가(미국 종목은 원화 환산 금액도), 전일 대비 등락률, 기간을 고를 수 있는 **차트**, **일별 시세**, 보유한 종목이면 **내 보유**(평가금액 · 평가손익 · 보유수량 · 수익률 · 평균단가 · 매입금액 등)

## 토스증권

- **발견** 탭 — **급상승 · 급하락 · 거래량** 순위
- **장 상태 줄** — 국내 · 미국 시장이 지금 열렸는지(장마감 · 휴장 · 개장 시각)와 코스피 · 코스닥 지수
- 종목 상세에만 있는 것
  - **호가 · 체결** — 실시간 호가창과 체결 내역
  - **기본 정보** — 시장 · 종목 유형 · 통화 · 시가총액 · 상한가 · 하한가 · 상장일 · 발행주식수 · 거래상태
  - **매수 유의사항** 표시(투자주의 · 투자경고 · 단기과열 등)
  - 내 보유에 **일간 손익 · 수수료·세금 · 매도가능** 수량까지
  - 매매 수수료 안내와 [매도] · [매수] 버튼(위 안내처럼 주문은 되지 않습니다)
- 토스 시세는 **국내 · 미국 종목만** 나옵니다. 다른 시장 종목은 검색 · 관심 등록은 되지만 "토스 시세 미지원 종목이에요 (국내·미국만 제공)" 로 표시됩니다

## 나무증권

- **보유** — 국내와 해외(**미국 달러 종목만**) 보유를 한 목록으로 합쳐 보여 주고, **전체 · 국내 · 해외** 칩으로 거릅니다
- **맨 위 요약** — **국내 평가금액(KRW)** · **해외 평가금액(USD)** · **원화 환산 합계**(적용한 환율 표시). 환율을 받지 못하면 원화 합계 대신 통화별 금액만 보여 줍니다("통화별 금액은 정확해요")
- 종목 상세 — 차트 · 일별 시세 · 내 보유
- **발견 탭과 호가 · 체결은 없습니다** — "나무증권은 호가·체결을 주지 않아 이 화면엔 없어요."
- 보유를 못 불러오면 "보유 정보를 불러오지 못했어요. 계좌가 없거나 조회 권한이 없을 수 있어요." 가 뜹니다 — 나무증권 계좌와 API 조회 권한을 확인하세요

## 한눈에 비교

| | 토스증권 | 나무증권 |
|---|:---:|:---:|
| 보유 · 관심 · 검색 · 차트 · 일별 시세 | ✓ | ✓ |
| 발견(급상승 · 급하락 · 거래량) | ✓ | — |
| 장 상태 · 지수 | ✓ | — |
| 호가 · 체결 · 기본 정보 | ✓ | — |
| 시세 · 보유 시장 | 국내 · 미국 | 국내 · 미국(USD) |

:::info[앱은 조금 달라요]
- 앱의 **나무증권** 화면은 **보유 종목(국내 · 해외 탭)과 종목 검색**만 있습니다. 관심 목록 · 차트는 웹에서 보세요
- 앱에서 Pro가 아닌 상태로 증권 화면을 열면 안내 없이 **홈으로 돌아갑니다**(웹은 "증권 구독이 필요해요" 안내가 뜹니다)
:::

## 연동이 아직 안 되어 있다면

Pro인데 연결한 증권사가 없으면 "증권 계정을 연결해 주세요" 안내와 **[설정에서 연결하기]** 가 나옵니다 — [증권사 연동하기](./securities-link.md)를 먼저 진행하세요.

:::info[증권 화면은 Pro 구독자를 위한 기능이에요]
증권 화면은 [Porest Pro](../subscription/subscription.md) 구독자를 위한 기능입니다. 구독 중이 아니면 메뉴에 아예 나타나지 않고, 웹에서 옛 북마크나 주소로 바로 들어가면 **"증권 구독이 필요해요"** 안내와 **[구독 보기]** 가 대신 열립니다. 서버도 증권 데이터 요청을 따로 막고 있어서, 화면을 우회해도 시세는 받아올 수 없습니다.
:::

## 자산 화면의 평가액은 실시간, 추이 그래프는 하루 한 번

[자산](../asset/overview.md) 화면에서 투자 자산의 평가액은 **10초마다** 지금 시세로 다시 계산되지만, **순자산 추이 그래프**에 남는 오늘 값은 **매일 오후 4시**에 하루 한 번만 찍힙니다. 장중에 둘이 달라 보이는 건 그래서입니다 — 자세한 내용은 [자산 개요](../asset/overview.md#투자-자산은-지금-금액과-추이-그래프가-따로-움직입니다)에서 다룹니다. 두 증권사를 연결했다면 이 금액은 [기본 증권사](./securities-link.md#두-곳을-연결했다면--기본-증권사)의 시세로 계산됩니다.
