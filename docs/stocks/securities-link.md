# 증권사 연동하기

토스증권 · 나무증권 계정을 연결하면 보유 종목과 시세를 Desk 안에서 바로 볼 수 있습니다. [Porest Pro 구독](../subscription/subscription.md)이 필요합니다.

## 연동 방법

1. 구독이 안 되어 있다면 먼저 Pro를 구독합니다
2. 증권 화면에서 연결할 증권사를 고르고, 증권사에서 발급받은 API 키를 입력합니다
3. 연결이 확인되면 바로 [증권 화면](./stocks.md)에서 데이터를 볼 수 있습니다

:::info[등록 버튼을 누르는 순간 실제로 검증합니다]
API 키는 저장하기 전에 그 자리에서 증권사 서버에 실제로 접속해 확인합니다. 잘못된 키를 입력하면 저장되지 않고 바로 오류가 뜨므로, "일단 등록해두고 나중에 화면을 열었을 때 안 되는" 상황은 생기지 않습니다.
:::

API 키는 암호화되어 저장되며, 평문으로는 어디에도 남지 않습니다.

## 나무증권을 쓴다면 — 알림 문자에 대해

나무증권은 접속 권한을 새로 발급받을 때마다 **등록해둔 휴대폰으로 보안 알림(문자)** 을 보냅니다. 이건 나무증권 자체의 보안 정책이라 Desk가 막을 수 있는 부분이 아닙니다.

- 나무 접속 권한의 유효기간은 정확히 24시간입니다. 유효기간이 끝나기 전에 Desk가 미리 캐시해두고 재사용하므로, 화면을 열 때마다 알림이 오지는 않습니다.
- 접속 권한을 재발급받는 건 실제로 접속이 끊겼을 때(24시간 경과 등)뿐이라, 평소 사용에서는 하루 한 번 정도로 그칩니다.
- 토스증권은 이런 보안 알림 정책이 없습니다.

## 연동 해제

연동을 끊으면 그 즉시 접속 권한이 사라져 더 이상 그 계정을 조회하지 않습니다. 다시 연결하려면 API 키를 새로 입력해야 합니다.
