# 증권사 연동하기

토스증권 · 나무증권에서 발급받은 **본인 API 키**를 등록하면 보유 종목과 시세를 Desk 안에서 바로 볼 수 있습니다. [Porest Pro 구독](../subscription/subscription.md)이 필요합니다.

## 연동 방법

1. 구독이 안 되어 있다면 먼저 Pro를 구독합니다
2. **설정 → 계정 → 증권 데이터 연동 → 증권사 연동**("토스·나무 등 증권사 API 키를 연결해요")을 누릅니다 — 이 줄은 Pro일 때만 보입니다
3. 연결할 증권사 카드에 키 두 개를 넣습니다. 칸 이름은 증권사마다 다릅니다

| 증권사 | 첫째 칸 | 둘째 칸 | 발급받는 곳 |
|---|---|---|---|
| 토스증권 | Client ID | Client Secret | 토스증권 개발자센터 |
| 나무증권 | App Key | App Secret | 나무증권 NH PLUG |

4. 두 칸을 모두 채우면 **[연결하기]** 가 눌립니다. 칸 오른쪽 눈 아이콘으로 입력한 값을 확인할 수 있습니다
5. 연결되면 "토스증권 계정을 연결했어요" 가 뜨고, 카드에 **연결됨** 표시와 "토스증권 API 키 연결됨 · 마지막 검증 · 2026-09-24" 가 나옵니다

증권 화면에 뜨는 "증권 계정을 연결해 주세요" 안내의 **[설정에서 연결하기]** 로도 설정으로 갈 수 있습니다. 웹은 설정의 첫 화면이 열리니 **계정**을 골라 들어가세요(앱은 연동 화면이 바로 열립니다).

:::info[연결하기를 누르는 순간 실제로 확인합니다]
키는 저장하기 전에 그 자리에서 증권사 서버에 실제로 접속해 확인합니다. 잘못된 키면 "인증정보가 올바르지 않아요" 가 뜨고 저장되지 않으므로, "일단 등록해 두고 나중에 화면을 열었을 때 안 되는" 상황은 생기지 않습니다.
:::

키는 서버에 암호화되어 저장되고, 등록한 뒤에는 화면에 다시 보여 주지 않습니다(연결됐는지만 표시).

## 두 곳을 연결했다면 — 기본 증권사

토스와 나무를 **둘 다** 연결하면, 기본이 아닌 카드에 **[이 증권사 시세로 자산 평가하기]** 가 생깁니다("가계부 자산은 여기서 고른 증권사 시세로 계산해요."). 누르면 "이제 ○○ 시세로 자산을 평가해요" 가 뜨고 그 카드에 **기본** 표시가 붙습니다.

- [자산](../asset/overview.md)의 투자 자산 금액은 이 **기본 증권사의 시세**로 계산됩니다
- 증권 화면은 두 증권사를 따로 보여 줍니다 — 데스크톱은 왼쪽 메뉴 **증권** 아래에 증권사가 하나씩, 모바일은 증권 화면 맨 위 탭으로 고릅니다. 처음 열 때는 기본 증권사가 먼저 나옵니다

## 나무증권을 쓴다면 — 알림톡에 대해

나무증권은 접속 권한(토큰)을 새로 발급할 때마다 **등록된 휴대폰으로 카카오 알림톡**을 보냅니다. 나무증권 자체의 보안 정책이라 Desk가 막을 수 있는 부분이 아닙니다.

- 나무 접속 권한은 **24시간** 동안 유효합니다. Desk는 한 번 받은 권한을 저장해 두고 끝날 때까지 다시 쓰므로, 화면을 열 때마다 알림톡이 오지는 않습니다
- 새로 발급하는 건 권한이 끝났거나 증권사가 무효라고 알려 왔을 때뿐이라, 평소에는 **하루 한 번 정도**입니다. 키를 처음 연결할 때도 확인하느라 한 번 옵니다
- 토스증권은 이런 알림이 없습니다

## 연동 해제

카드의 **[연결 해제]** 를 누르면 **확인 없이 바로** 끊기고 "○○ 연결을 해제했어요" 가 뜹니다. 그 증권사는 더 이상 조회하지 않고, 다시 연결하려면 키를 새로 입력해야 합니다.
