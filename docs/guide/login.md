# 로그인하기

Desk는 아이디 · 비밀번호를 따로 만들지 않습니다. **POREST 통합 로그인(SSO)** 계정 하나로 Desk를 포함한 POREST 서비스에 로그인합니다.

## 웹에서 로그인

1. [desk.porest.cloud](https://desk.porest.cloud) 에 들어가 "SSO 계정으로 로그인하세요" 아래 **[SSO 로그인]** 을 누릅니다

3. 로그인되면 자동으로 Desk 홈으로 돌아옵니다

### 통합 로그인 화면

- **[Google로 로그인]** — [설정 → 계정 → 연결된 계정](../settings/account.md#연결된-계정)에서 Google을 **먼저 연결해 둔 계정만** 쓸 수 있습니다. 연결하지 않은 Google 계정으로 누르면 "연동된 계정이 없습니다. 로그인 후 계정 연결을 먼저 진행해 주세요." 가 뜹니다 — Google로 새로 가입되지는 않습니다
- **비밀번호 찾기** — 가입한 **아이디와 이메일**을 넣으면 그 이메일로 **임시 비밀번호**가 갑니다("가입된 이메일이면 임시 비밀번호를 발송했습니다"). 임시 비밀번호로 로그인한 뒤 [설정 → 계정 → 비밀번호 변경](../settings/account.md#비밀번호-변경)에서 바꿔 두세요. 메일이 안 보이면 스팸함을 확인하세요
- **아이디 찾기**는 없습니다

:::warning[비밀번호를 5번 틀리면 10분 동안 잠겨요]
같은 아이디로 비밀번호를 **5번 연달아 틀리면 10분 동안** 로그인이 막힙니다 — "로그인 시도 횟수 초과로 계정이 일시적으로 잠겼습니다. 10분 후 다시 시도해주세요". 로그인에 성공하면 틀린 횟수는 다시 0이 됩니다. 이 횟수는 [금액 가리기](../settings/account.md#금액-가리기)를 풀 때 · [이용 해지](../settings/account.md#desk-이용-해지) 때의 비밀번호 확인과 **함께 셉니다.**
:::

### 회원가입

통합 로그인 화면 아래 **회원가입**에서 만듭니다.

| 칸 | 규칙 |
|---|---|
| 아이디 | 4 ~ 20자, 영문 · 숫자 · 밑줄(_)만. **[중복확인]** 을 눌러 확인합니다 |
| 이름 | 20자 이하 |
| 이메일 | 비밀번호 찾기 · 본인 확인 코드가 이 주소로 갑니다 |
| 비밀번호 · 비밀번호 확인 | **8자 이상 · 특수문자 1자 이상** |
| 서비스 가입 지역 | '오늘'과 통계의 하루를 이 지역 기준으로 셉니다. 나중에 [표시 설정 → 기준 지역](../settings/display.md#기준-지역)에서 바꿀 수 있습니다 |

### 로그인은 얼마나 유지되나요

한 번 로그인하면 **마지막으로 쓴 때부터 7일** 동안 유지됩니다 — 쓸 때마다 다시 7일로 늘어나므로, 자주 쓰면 로그아웃될 일이 없습니다. 7일 넘게 들어오지 않았거나 [로그인된 기기](../settings/account.md#로그인된-기기)에서 끊긴 뒤에 들어오면 통합 로그인 화면으로 넘어가고, 다시 로그인하면 **하던 화면으로 돌아옵니다.** 통합 로그인이 아직 살아 있으면 아이디 · 비밀번호를 묻지 않고 "로그인 확인 중..." 뒤 곧바로 돌아옵니다.

:::info[이용을 해지한 계정으로 로그인하면]
[desk 이용 해지](../settings/account.md#desk-이용-해지)를 마친 계정으로 로그인하면 오류 대신 **"이용 해지가 끝났어요"** 완료 화면이 다시 나옵니다. 해지한 계정은 되살릴 수 없고, 같은 아이디 · 이메일로 새로 가입할 수도 없습니다.
:::

## 앱 설치

앱은 스토어에 올라가 있지 않아 직접 설치합니다. 웹의 **전체 → 앱 받기** 또는 [desk.porest.cloud/download](https://desk.porest.cloud/download) 에 들어가면 지금 받을 수 있는 버전과 빌드 번호가 보입니다. 앱 없이 브라우저만으로 써도 됩니다.

| | 받는 방법 | 필요한 OS |
|---|---|---|
| **Android** | **[APK 내려받기]** 로 받아 바로 설치합니다. 처음엔 "출처를 알 수 없는 앱" 설치를 허용해야 할 수 있습니다. 이미 깔려 있으면 지우지 않고 덮어써도 데이터는 그대로입니다 | Android 7.0 이상 |
| **iOS** | 서명되지 않은 IPA라 그대로는 설치되지 않습니다. 컴퓨터에서 **본인 Apple ID로 서명**해야 하고, 무료 Apple ID면 **7일마다 다시 서명**해야 합니다. **AltStore**에 페이지의 소스 주소를 **[주소 복사]** 해 추가하면 새 버전을 AltStore에서 받고 서명도 알아서 갱신됩니다(컴퓨터를 켜 둔 경우). Sideloadly 같은 도구를 쓰면 **[IPA 내려받기]** | iOS 15.0 이상 |

### Android — 설치 · 업데이트 시 나오는 보안 경고 처리하기

스토어를 거치지 않고 APK를 직접 설치·업데이트하기 때문에, 삼성 기기는 기본적으로 이 설치를 막습니다.
아래 순서대로 한 번만 풀어주면 됩니다.

**1. 설정 → 보안 및 개인정보 보호로 이동**

![설정 앱의 보안 및 개인정보 보호 메뉴](/img/screens/android-settings-security-menu.png)

**2. 계정 보안 → 보안 위험 자동 차단으로 이동**

"인증되지 않은 출처의 앱 차단" 항목이 바로 이 설치를 막는 기능입니다.

![계정 보안 화면](/img/screens/android-account-security.png)

**3. 보안 위험 자동 차단을 잠시 꺼줍니다**

"사용 안 함"으로 전환하면 30분 동안만 꺼져 있다가 자동으로 다시 켜집니다. 설치·업데이트가 끝나면
따로 되돌릴 필요 없이 30분 뒤 알아서 원래 상태로 돌아갑니다.

![보안 위험 자동 차단 끄기](/img/screens/android-auto-blocker-off.png)

**4. APK 실행 시 "앱 검사 권장됨" 화면이 뜨면 → 검사 없이 설치**

Google Play 프로텍트가 스토어 밖에서 온 앱을 검사하겠냐고 묻습니다. **검사 없이 설치**를 선택하면
바로 설치가 진행됩니다.

![Play 프로텍트 앱 검사 권장 화면](/img/screens/android-play-protect-scan.png)

**5. "잠재적으로 유해한 앱 감지됨" 경고가 떠도 정상입니다**

다운로드 페이지 링크를 통해 막 설치된 앱이라 Play 프로텍트가 피싱 패턴으로 오탐하는 경우가 많습니다.
**닫기**를 눌러 넘어가면 됩니다.

![잠재적으로 유해한 앱 감지됨 팝업](/img/screens/android-harmful-app-detected.png)

**6. 이후에도 계속 경고가 뜬다면 → Play 프로텍트의 "안전하지 않은 앱" 목록에서 직접 실행**

앱을 삭제하지 말고, 목록에서 Porest Desk를 눌러 뜨는 확인창에서 **열기**를 선택하면 정상적으로
실행됩니다.

![안전하지 않은 앱 목록](/img/screens/android-unsafe-app-list.png)

![안전하지 않은 앱 목록에서 열기 선택](/img/screens/android-unsafe-app-open-confirm.png)

:::tip[매번 이 과정을 거쳐야 하나요?]
새 APK를 설치·업데이트할 때마다(서명이 바뀔 때마다) 다시 나올 수 있는 경고입니다. 앱을 삭제하지 말고
그때그때 위 순서대로 **닫기 / 열기**로 넘어가면 됩니다.
:::

## 앱에서 로그인

앱의 **[SSO 로그인]** 을 누르면 앱 안이 아니라 **휴대폰의 기본 브라우저**가 열립니다(구글 로그인 등 일부 방식은 인앱 브라우저를 막기 때문입니다). 로그인을 마치면 브라우저가 자동으로 앱으로 돌아옵니다.

:::tip[브라우저에서 앱으로 안 돌아올 때]
로그인은 됐는데 앱 화면으로 안 돌아온다면, 브라우저 화면을 닫고 Desk 앱을 다시 열어보세요. 로그인 상태는 유지되어 있습니다. 로그인 창을 너무 오래 열어 두었다면 "로그인 시간이 지났어요. 다시 로그인해 주세요." 가 뜨니 처음부터 다시 누르세요.
:::

## 앱 업데이트

스토어를 쓰지 않아 자동 업데이트가 없습니다. 대신 앱이 새 버전을 알려 줍니다.

- **새 버전이 나오면** 앱을 열 때 "새 버전 ○○ 이 나왔어요" 화면이 **"이번에 달라진 점"** 과 함께 뜹니다. **[설치]** 를 누르거나, **[취소]** 로 넘어갈 수 있습니다 — 취소한 버전은 다시 묻지 않고, 그다음 버전이 나오면 다시 뜹니다
- 언제든 **설정 → 앱 환경 → 업데이트**에서 확인할 수 있습니다("최신 버전이에요" · "지금 빌드 N")
- **Android**는 앱 안에서 내려받아 설치 화면을 엽니다(앱에서 못 받으면 브라우저로 엽니다). 삼성 휴대폰에서 자동 차단이 켜져 있으면 "삼성 자동 차단을 꺼야 설치돼요" 안내와 **[설정 열기]** 가 나옵니다 — 아래 [보안 경고 처리하기](#android--설치--업데이트-시-나오는-보안-경고-처리하기)를 보세요
- **iOS**는 AltStore로 넘어가 받습니다

:::warning[꼭 받아야 하는 업데이트]
옛 버전을 계속 쓰면 기록이 잘못 남을 수 있는 변경이 들어간 경우에는 "이번 버전부터 꼭 업데이트해야 해요. 받기 전에는 앱을 쓸 수 없어요." 가 뜨고 넘어갈 수 없습니다. [취소]를 누르면 "업데이트가 꼭 필요한 내역이 포함되어 있습니다" 가 뜨고, Android는 앱이 닫힙니다. 이 경우는 매번 묻습니다.
:::

## 로그인된 기기 확인

여러 기기에서 로그인해 두었다면 **설정 → 계정 → 보안 → 로그인된 기기**에서 목록을 확인하고, 더 이상 쓰지 않는 기기는 원격으로 로그아웃할 수 있습니다. 자세한 내용은 [계정 → 로그인된 기기](../settings/account.md#로그인된-기기)에서 다룹니다.
