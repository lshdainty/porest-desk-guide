# 화면 구성

로그인하면 가장 먼저 **홈**이 나옵니다. 순자산(총 자산 · 총 부채), 이번 달 수입 · 지출, 하루 평균 지출, 오늘 쓴 돈, 카테고리별 지출, 예산, 다가오는 결제, 할 일 · 일정 미리보기를 한눈에 보여 주고, 각 카드를 누르면 해당 화면으로 이동합니다.

웹은 창 너비가 **768px보다 좁으면** 모바일 화면으로 바뀝니다. 휴대폰 브라우저에서는 모바일 화면이, 태블릿 · 컴퓨터에서는 데스크톱 화면이 나옵니다.

## 데스크톱 화면

### 왼쪽 메뉴

두 묶음으로 나뉩니다.

- **워크스페이스**: 홈 · 자산 · 증권 · 가계부 · 통계·분석 · 예산
- **기록**: 캘린더 · 할 일 · 더치페이 · 메모 · 카드 혜택

**증권**은 [Pro 구독](../subscription/subscription.md) 중일 때만 보이고, 증권사를 둘 이상 연결했으면 그 아래에 증권사별 메뉴가 펼쳐집니다. 맨 아래에는 내 이름과 이메일이 보입니다. **설정**은 왼쪽 메뉴가 아니라 위쪽 바의 톱니바퀴로 들어갑니다.

### 위쪽 바

왼쪽부터 차례로:

- **메뉴 접기**: 왼쪽 메뉴를 아이콘만 남기고 접었다 폅니다 — <kbd>Cmd</kbd>+<kbd>B</kbd>(윈도우 · 리눅스는 <kbd>Ctrl</kbd>+<kbd>B</kbd>)로도 됩니다
- **검색창**: 아직 준비 중입니다 — 글자를 받지 않고, 누르면 "검색 기능 준비 중" 안내 화면으로 넘어갑니다
- **눈 아이콘**: [금액 가리기](../settings/account.md#금액-가리기) 설정으로 바로 갑니다. 가려 둔 금액이 있으면 눈에 사선이 그어집니다
- **해 · 달 아이콘**: 누르면 **라이트 · 다크 · 시스템** 메뉴가 열려 테마를 바로 바꿉니다([표시 설정](../settings/display.md#테마)과 같은 값)
- **알림벨**: 받은 알림 목록이 펼쳐집니다. 안 읽은 알림이 있으면 빨간 점이 붙습니다 — 자세한 건 [알림](../settings/notifications.md)
- **톱니바퀴**: 설정 화면으로 갑니다. 처음 열면 [카테고리 관리](../settings/category.md)가 보이고, 왼쪽 목록에서 다른 설정을 고릅니다
- **[+ 내역 추가]**: 어느 화면에서든 [거래 추가](../expense/transactions.md) 창을 엽니다

:::tip[찾을 게 있으면 화면 안의 검색을 쓰세요]
위쪽 바의 검색창은 아직 결과를 돌려주지 않습니다. 지금은 화면마다 따로 있는 검색을 쓰세요 — [메모](../memo/memo.md)는 제목 · 내용, [카테고리 관리](../settings/category.md)와 [카드 혜택](../asset/card-benefit.md)은 이름으로 찾습니다. 거래는 [가계부 필터](../expense/transactions.md)로 좁혀 보세요.
:::

## 모바일 화면

모바일 웹과 앱의 구성은 같습니다. 화면 아래 탭 바로 주요 화면을 오갑니다.

- **기본 탭**: 홈 · 가계부 · **+** · 캘린더 · 전체
- **가계부 탭**: 가계부 · 자산 · 통계 · 예산 화면에 들어가면 탭이 **← · 가계부 · 자산 · 통계 · 예산**으로 바뀝니다. 맨 왼쪽 **←** 를 누르면 홈으로 돌아가고 탭도 기본으로 돌아옵니다

가운데 **+** 는 **캘린더 화면에서는 일정 추가**, 그 밖의 화면에서는 **거래 추가**를 엽니다.

![모바일 홈 화면과 하단 기본 탭바(홈 · 가계부 · + · 캘린더 · 전체)](/img/screens/mobile-tabbar.png)

화면 맨 위 제목 줄의 오른쪽 아이콘은 홈에서는 **알림벨**(알림 화면), 다른 화면에서는 **돋보기**입니다. 돋보기를 누르면:

- **모바일 웹**: 데스크톱 검색창처럼 "검색 기능 준비 중" 안내만 나옵니다
- **앱**: **거래 검색** 화면이 열립니다. 거래의 **메모**에 들어간 글자로 찾고, 전체 · 지출 · 수입 탭과 오른쪽 위 **고급 필터**(금액 범위 · 기간)로 좁힙니다. 결과는 가계부처럼 날짜별로 묶여 나옵니다

### 전체

**전체** 탭은 모든 화면으로 가는 메뉴입니다. 위의 **메뉴 검색**에 이름을 넣으면 바로 좁혀집니다.

| 묶음 | 메뉴 |
|---|---|
| 돈 관리 | 가계부 · 자산 · 증권(Pro) · 예산 · 저축 목표 · 통계·분석 · 반복 거래 · 계좌·카드 관리 |
| 일상 | 캘린더 · 할 일 · 메모 · 더치페이 · 카드 혜택 |
| 개인화 | 카테고리 · 프리셋 · 표시 설정 |
| 계정·시스템 | 설정 · 알림 설정 · 데이터 내보내기 · 계정 · 앱 받기 |

앱의 전체 메뉴는 조금 다릅니다 — 돈 관리에 **결제 문자로 기록**과 **결제 알림 수신함**(안드로이드만)이 더 있고, **앱 받기**는 없습니다.

![모바일 웹의 전체 메뉴 — 메뉴 검색과 돈 관리 · 일상 · 개인화 · 계정·시스템 네 묶음](/img/screens/mobile-more.png)

### 탭 바 없이 열리는 화면

메모 · 할 일 · 더치페이 · 카드 혜택 · 증권 · 설정 · 알림 화면은 탭 바 없이 화면 전체를 채우고, 왼쪽 위에 **←** 가 있습니다. **모바일 웹**에서 이 ← 는 **전체** 메뉴로 돌아갑니다(홈의 알림벨로 연 알림 화면도 마찬가지입니다). **앱**에서는 들어오기 전 화면으로 돌아갑니다.

:::tip[목록의 행을 옆으로 밀기]
모바일에서는 거래 · 할 일 · 메모 목록과 계좌·카드 · 예산 · 저축 목표 · 반복 거래 · 프리셋 · 태그 · 라벨 관리 목록의 행을 왼쪽으로 밀면 수정 · 삭제 같은 버튼이 나타납니다. 한 번에 한 행만 열리고, 스크롤하면 닫힙니다.
:::

## 창은 두 가지입니다 — 입력 창과 확인 창

Desk에서 뜨는 창은 **무언가를 입력 · 확인하는 창**과 **되돌릴 수 없는 일을 묻는 확인 창** 두 가지이고, 닫는 방법이 서로 다릅니다.

| | 입력 · 상세 창 | 확인 창 |
|---|---|---|
| 예 | 거래 추가 · 수정, 상세 보기, 필터, 설정 폼 | 삭제할까요? · 환불 취소 · 지금 결제 |
| 오른쪽 위 **×** | 있습니다 | **없습니다** |
| <kbd>Esc</kbd> · 창 바깥 누르기 | 닫힙니다 | **닫히지 않습니다** |
| 닫는 방법 | ×, <kbd>Esc</kbd>, 바깥 누르기, [취소] | **[취소] 만** |

:::info[확인 창이 잘 안 닫히는 게 아니라, 일부러 그렇게 돼 있어요]
삭제처럼 **되돌릴 수 없는 일**은 실수로 창을 닫아 흐지부지되거나, 반대로 실수로 확정되는 걸 막아야 합니다. 그래서 확인 창은 바깥을 눌러도 <kbd>Esc</kbd>를 눌러도 닫히지 않고, 창이 열릴 때 커서가 **[취소]** 에 먼저 놓입니다 — 뜨자마자 <kbd>Enter</kbd>를 눌러도 삭제되지 않고 취소됩니다.
:::

## 모바일과 데스크톱의 차이

같은 기능이라도 모바일에서는 여는 방식이 다릅니다.

- **상세 화면이 하단 시트로 열립니다**: 거래 · 할 일 · 메모 상세는 데스크톱처럼 가운데 뜨는 창이 아니라 화면 아래에서 올라오는 시트로 열리고, **삭제(빨강) · 수정(파랑)** 이 화면 폭 전체를 채우는 큰 버튼으로 바뀝니다. 데스크톱도 같은 자리에 같은 순서로 두 버튼이 있지만 창 너비에 맞춘 작은 크기입니다 — 삭제는 왼쪽 끝에 **옅은 빨강**, 수정은 오른쪽 끝에 **파랑**입니다.
- **캘린더는 한 단계 더 거칩니다**: 날짜를 누르면 그날의 일정 목록이 먼저 뜨고, 그중 하나를 한 번 더 눌러야 상세로 들어갑니다 — 데스크톱은 일정을 누르면 바로 상세 카드가 뜹니다.
- **설정은 목록 → 하위 화면으로 들어갑니다**: 데스크톱의 좌우 2단 구성(왼쪽 메뉴 · 오른쪽 내용) 대신, 모바일은 설정 메뉴 전체를 한 화면 가득 채운 목록으로 먼저 보여 주고, 항목을 누르면 그 설정 화면으로 넘어갑니다.

## 앱에서만 되는 것

앱은 모바일 웹과 거의 같은 구성이지만, 다음은 앱에서만 됩니다.

- **결제 알림 수신함**(안드로이드): 카드 결제 알림을 읽어 거래 후보로 모아 두고, 내가 확인해야 지출로 기록됩니다 — [문자로 자동 반영](../expense/transactions.md#문자로-자동-반영) 참고
- **앱 잠금**: 생체인증(지문 · 얼굴)으로 앱을 잠급니다 — [계정 설정](../settings/account.md#앱-잠금-앱)
- **거래 검색**: 위의 돋보기 — 모바일 웹은 아직 준비 중입니다
- **내보내기 공유**: [데이터 내보내기](../settings/data-transfer.md#내보내기) 파일을 공유 창으로 바로 다른 앱에 보냅니다

### 기기 뒤로가기는 홈으로 돌아갑니다

안드로이드의 뒤로가기 버튼(또는 화면 가장자리를 쓸어넘기는 제스처)은 **지금까지 지나온 화면을 한 칸씩 되짚지 않고 바로 홈으로** 옵니다.

| 지금 있는 곳 | 뒤로가기를 누르면 |
|---|---|
| 시트 · 확인창 · 설정처럼 위에 얹힌 화면 | 그 화면만 닫힙니다 |
| 거래 상세처럼 탭 안에서 더 들어간 화면 | 한 칸 뒤로 나옵니다 |
| 가계부 · 자산 · 통계 · 예산 · 캘린더 · 전체 탭 | **바로 홈** |
| 홈 | **앱이 닫힙니다** |

:::info[탭을 오간 순서는 기억하지 않아요]
홈 → 통계 → 예산 순서로 움직였더라도 뒤로가기 한 번에 통계를 거치지 않고 홈으로 옵니다. 탭 사이를 옮겨 다닌 기록을 되짚는 대신 **"돌아갈 곳은 언제나 홈"** 으로 단순하게 두었습니다 — 그래서 홈에서 한 번 더 누르면 앱이 닫힙니다.
:::
