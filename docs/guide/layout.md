# 화면 구성

로그인하면 가장 먼저 **홈(대시보드)** 이 나옵니다. 순자산, 이번 달 수입 · 지출, 예산 진행률, 오늘의 지출, 다가오는 결제, 할 일 · 일정 미리보기를 한눈에 보여주고, 각 카드를 누르면 해당 화면으로 바로 이동합니다.

## 데스크톱 화면

왼쪽에 항상 보이는 메뉴에서 할 일 · 캘린더 · 메모 · 가계부 · 자산 · 더치페이 · 증권 화면을 오갑니다. 위쪽 아이콘들은 어느 화면에서든 똑같이 있습니다.

- **메뉴 접기**: 맨 왼쪽 버튼으로 왼쪽 메뉴를 접었다 폅니다 — <kbd>Cmd</kbd>+<kbd>B</kbd>(윈도우 · 리눅스는 <kbd>Ctrl</kbd>+<kbd>B</kbd>)로도 같은 동작을 합니다
- **검색**: 아직 준비 중인 기능입니다 — 입력창은 글자를 받지 않고, 누르면 "검색 기능 준비 중 · v0.7 에 추가 예정" 안내 화면으로 넘어갑니다
- **눈 아이콘**: [금액 가리기](../settings/account.md#금액-가리기) 설정으로 바로 이동하는 단축 버튼입니다
- **해 · 달 아이콘**: [표시 설정](../settings/display.md)의 테마를 라이트 · 다크로 빠르게 전환합니다(시스템 설정을 따르게 하려면 표시 설정에서 다시 골라야 합니다)
- **알림벨**: 받은 알림을 모아 보는 드롭다운입니다 — [알림 설정](../settings/notifications.md)으로 가는 링크도 여기 있습니다
- **톱니바퀴**: 설정 화면으로 바로 이동합니다

:::tip[찾을 게 있으면 화면 안의 검색을 쓰세요]
헤더의 검색창은 아직 결과를 돌려주지 않습니다. 지금 무언가를 찾아야 한다면 화면마다 따로 있는 검색을 쓰세요 — [메모](../memo/memo.md)는 제목 · 내용 검색, [카테고리 관리](../settings/category.md)와 [카드 혜택](../asset/card-benefit.md)은 이름 검색이 각 화면 안에 있습니다.
:::

## 모바일 화면

화면 아래 탭 바로 주요 화면을 오갑니다. 탭 구성은 상황에 따라 두 가지로 바뀝니다.

- **기본 탭**: 홈 · 가계부 · **+** (빠른 추가) · 캘린더 · 전체메뉴
- **가계부 탭**: 가계부 화면에 들어가면 거래 · 자산 · 통계 · 예산으로 탭이 바뀝니다

![모바일 홈 화면과 하단 기본 탭바(홈 · 가계부 · + · 캘린더 · 전체메뉴)](/img/screens/mobile-tabbar.png)

**전체메뉴**에서는 검색으로 원하는 화면을 바로 찾아 이동할 수 있어, 탭 바에 없는 메모 · 더치페이 · 증권 · 설정 화면도 여기서 들어갑니다.

화면 오른쪽 위 아이콘은 홈에서는 **알림벨**, 다른 화면에서는 **돋보기**로 바뀝니다 — 이 돋보기도 데스크톱 검색창과 마찬가지로 준비 중 안내 화면으로만 이어집니다.

메모 · 할 일 · 더치페이 · 카드 혜택 · 증권 · 설정 · 알림 화면은 탭 바 없이 화면 전체를 채우고, 왼쪽 위 뒤로가기로 이전 화면으로 돌아갑니다.

:::tip[거래내역 옆으로 밀기]
거래내역 등 목록 화면에서 행을 옆으로 밀면 수정 · 삭제 같은 동작이 나타납니다. 스크롤하면 자동으로 닫힙니다.
:::

## 창은 두 가지입니다 — 입력 창과 확인 창

Desk에서 뜨는 창은 **무언가를 입력 · 확인하는 창**과 **되돌릴 수 없는 일을 묻는 확인 창** 두 가지이고, 닫는 방법이 서로 다릅니다.

| | 입력 · 상세 창 | 확인 창 |
|---|---|---|
| 예 | 거래 추가 · 수정, 상세 보기, 필터, 설정 폼 | 삭제할까요? · 환불 취소 · 지금 결제 |
| 오른쪽 위 **×** | 있습니다 | **없습니다** |
| <kbd>Esc</kbd> · 창 바깥 누르기 | 닫힙니다 | **닫히지 않습니다** |
| 닫는 방법 | ×, <kbd>Esc</kbd>, 바깥 누르기, [취소] | **[취소] 만** |

:::info[확인 창이 잘 안 닫히는 게 아니라, 일부러 그렇게 돼 있어요]
삭제처럼 **되돌릴 수 없는 일**은 실수로 창을 닫아 흐지부지되거나, 반대로 실수로 확정되는 걸 막아야 합니다. 그래서 확인 창은 바깥을 눌러도 <kbd>Esc</kbd>를 눌러도 닫히지 않고, 창이 열릴 때 커서가 **[취소]** 에 먼저 놓입니다 — 뜨자마자 <kbd>Enter</kbd>를 눌러도 삭제되지 않고 취소됩니다.
:::

## 모바일과 데스크톱의 차이

같은 기능이라도 모바일에서는 상세 화면이 여는 방식이 다릅니다.

- **상세 화면이 하단 시트로 열립니다**: 거래 · 할 일 · 메모 상세는 데스크톱처럼 가운데 뜨는 창이 아니라 화면 아래에서 올라오는 시트로 열리고, **삭제(빨강) · 수정(파랑)** 이 화면 폭 전체를 채우는 큰 버튼으로 바뀝니다. 데스크톱도 같은 자리에 같은 순서로 두 버튼이 있지만 창 너비에 맞춘 작은 크기입니다 — 삭제는 왼쪽 끝에 **옅은 빨강**, 수정은 오른쪽 끝에 **파랑**입니다.
- **캘린더는 한 단계 더 거칩니다**: 날짜를 누르면 그날의 일정 목록이 먼저 뜨고, 그중 하나를 한 번 더 눌러야 상세로 들어갑니다 — 데스크톱은 일정을 누르면 바로 상세 카드가 뜹니다.
- **설정은 목록 → 하위 화면으로 드릴다운합니다**: 데스크톱의 좌우 2단 구성(왼쪽 메뉴 · 오른쪽 내용) 대신, 모바일은 설정 메뉴 전체를 한 화면 가득 채운 목록으로 먼저 보여주고, 항목을 누르면 그 설정 화면으로 완전히 넘어갑니다. [카테고리 관리](../settings/category.md)처럼 일부 화면은 수정 시트에 데스크톱에는 없는 기능(거래 옮기기 등)이 추가로 보이기도 합니다.

## 앱 화면

앱은 모바일 웹과 거의 같은 구성입니다. 다만 앱에서만 되는 것들이 있습니다.

- **알림 자동 인식**(Android): 카드사 결제 알림 · 문자를 앱이 자동으로 읽어 거래내역 후보로 띄웁니다 — [가계부 자동 반영](../expense/transactions.md#문자로-자동-반영) 참고
- **앱 잠금**: 생체인증(지문 · 얼굴)으로 앱을 잠글 수 있습니다 — [계정 설정](../settings/account.md)
- **밤하늘**: 할 일을 완료할 때마다 별빛이 쌓여 별자리가 채워지는 화면 — [할 일](../todo/todo.md#별자리-도감) 참고

### 기기 뒤로가기는 홈으로 돌아갑니다

안드로이드의 뒤로가기 버튼(또는 화면 가장자리를 쓸어넘기는 제스처)은 **지금까지 지나온 화면을 한 칸씩 되짚지 않고 바로 홈으로** 옵니다.

| 지금 있는 곳 | 뒤로가기를 누르면 |
|---|---|
| 시트 · 확인창 · 설정처럼 위에 얹힌 화면 | 그 화면만 닫힙니다 |
| 거래 상세처럼 탭 안에서 더 들어간 화면 | 한 칸 뒤로 나옵니다 |
| 가계부 · 자산 · 통계 · 예산 · 캘린더 · 더보기 탭 | **바로 홈** |
| 홈 | **앱이 닫힙니다** |

:::info[탭을 오간 순서는 기억하지 않아요]
홈 → 통계 → 예산 순서로 움직였더라도 뒤로가기 한 번에 통계를 거치지 않고 홈으로 옵니다. 탭 사이를 옮겨 다닌 기록을 되짚는 대신 **"돌아갈 곳은 언제나 홈"** 으로 단순하게 두었습니다 — 그래서 홈에서 한 번 더 누르면 앱이 닫힙니다.
:::
