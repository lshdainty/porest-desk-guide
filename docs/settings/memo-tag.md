# 메모 태그

[메모](../memo/memo.md)에 붙이는 태그를 만들고 관리합니다. 설정의 **메모 태그**에서 엽니다(모바일 설정 목록에서는 **태그 · 라벨** 묶음 안에 있습니다). 새로 만든 태그는 메모를 추가 · 수정할 때 바로 고를 수 있습니다.

태그는 이름순으로 놓이고, 태그마다 **"N건에 사용 중"** 으로 그 태그가 붙은 메모 수가 보입니다.

:::info[태그를 먼저 만들어야 메모에서 고를 수 있어요]
메모 추가 · 수정 폼의 태그 선택칸에는 여기서 만든 태그와 "태그 없음"만 뜹니다 — 목록이 비어 있으면 "태그 없음"만 고를 수 있으니, 분류해서 쓰고 싶다면 여기서 먼저 태그를 만들어두세요. 메모 하나에는 태그를 하나만 붙일 수 있습니다.
:::

## 태그 생성

1. **[+ 태그 추가]**
2. **이름**과 **색상**(10가지, 처음엔 첫 칸인 빨강)을 정합니다 — 위쪽 **미리보기**에 바로 반영됩니다
3. **[태그 추가]**(앱은 **[저장]**)

이름은 앞뒤 공백을 떼고 저장하며, 비워 두면 저장되지 않습니다(웹은 "이름을 입력해 주세요.", 앱은 **[저장]** 이 눌리지 않습니다).

- **웹은 12자까지**: 칸 아래에 `0/12` 처럼 글자 수가 보이고, 넘기면 "이름은 12자 이내로 입력해 주세요." 가 뜹니다. 앱에는 이 제한이 없어 50자까지 저장되지만, 그렇게 만든 12자 넘는 태그는 웹에서 고칠 때 12자 안으로 줄여야 저장됩니다
- **같은 이름의 태그는 하나만**: 웹은 저장하기 전에 "같은 이름의 태그가 이미 있어요." 로 막습니다. 영문 대소문자만 다른 이름(예: Idea · idea)도 같은 이름으로 보는데, 이 경우는 저장 버튼을 누른 뒤에야 "이미 같은 이름의 태그가 있어요" 가 뜨고 저장되지 않습니다. 앱은 미리 확인하지 않아, **[저장]** 을 누르면 창이 닫히면서 같은 안내가 뜨고 태그는 만들어지지 않습니다
- 삭제한 태그의 이름은 다시 쓸 수 있습니다

:::info[태그 색은 이 목록에서만 쓰여요]
태그 색은 이 목록의 태그 아이콘 색입니다. 메모 화면의 태그 칩이나 메모 카드에는 쓰이지 않습니다 — 메모 카드의 색은 메모를 쓸 때 **색상**에서 따로 고릅니다.
:::

## 태그 수정

태그 행을 누르면 같은 폼(**태그 수정**)이 열려 이름 · 색상을 바꿀 수 있습니다. 모바일에서는 행을 왼쪽으로 밀어 나오는 **[수정]** 으로도 열립니다. 이름을 바꾸면 그 태그를 쓰던 메모에도 새 이름이 그대로 붙습니다.

## 태그 삭제

데스크톱은 행의 **휴지통 아이콘**을, 모바일은 행을 왼쪽으로 밀어 나오는 **[삭제]** 를 누르고, **태그 삭제** 확인 창에서 **[삭제]** 를 누릅니다.

![태그 삭제 확인 — 이 태그를 쓰는 메모는 몇 건인지까지 알려줍니다](/img/screens/settings-memo-tag-delete-confirm.png)

:::danger[삭제하면 그 태그가 붙어있던 메모는 "태그 없음"이 됩니다]
확인 창이 **"○○" 태그를 삭제하면 이 태그를 쓰는 메모 N건은 태그 없음으로 남아요.** 처럼 영향받는 개수까지 미리 알려줍니다. 태그를 삭제해도 **메모 자체는 지워지지 않고**, 그 메모들에서 태그만 빠집니다 — [할 일 태그 삭제](./todo-tag.md#태그-삭제)와 같은 방식입니다.
:::
