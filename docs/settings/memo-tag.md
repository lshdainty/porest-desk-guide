# 메모 태그

[메모](../memo/memo.md)에 붙이는 태그를 만들고 관리합니다. 새로 만든 태그는 메모를 추가 · 수정할 때 바로 고를 수 있습니다.

</TabItem>
</Tabs>

:::info[태그를 먼저 만들어야 메모에서 고를 수 있어요]
메모 추가 · 수정 폼의 태그 선택칸에는 여기서 만든 태그와 "태그 없음"만 뜹니다 — 목록이 비어 있으면 태그 없음만 고를 수 있으니, 분류해서 쓰고 싶다면 여기서 먼저 태그를 만들어두세요.
:::

## 태그 생성

1. **[+ 태그 추가]**
2. **이름**(최대 12자 · 같은 이름의 태그가 이미 있으면 저장하기 전에 알려 줍니다)과 **색상**을 정합니다
3. **[태그 추가]**

## 태그 삭제

행의 **휴지통 아이콘**을 누르고 확인 창에서 **[삭제]** 를 누릅니다.

![태그 삭제 확인 — 이 태그를 쓰는 메모는 몇 건인지까지 알려줍니다](/img/screens/settings-memo-tag-delete-confirm.png)

:::danger[삭제하면 그 태그가 붙어있던 메모는 "태그 없음"이 됩니다]
확인 창이 "이 태그를 쓰는 메모 N건은 태그 없음으로 남아요"처럼 영향받는 개수까지 미리 알려줍니다. 태그를 삭제해도 **메모 자체는 지워지지 않고**, 그 메모들에서 태그만 빠집니다 — [할 일 태그 삭제](./todo-tag.md#태그-삭제)와 같은 방식입니다.
:::
