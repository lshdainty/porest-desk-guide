# 알림 설정

![알림 설정 — 종류별 알림을 켜고 끄고, 각 알림이 정확히 언제 오는지 안내가 붙어 있습니다](/img/screens/settings-notifications.png)

## 알림 종류별 켜고 끄기

| 알림 | 오는 시점 |
|---|---|
| 결제 알림 | 결제 예정일 D-1, 결제일 당일 |
| 예산 알림 | 카테고리 예산 85% · 100% 도달 시 |
| 자동 기록 알림 | 반복 거래가 자동으로 기록되었을 때 |
| 더치페이 알림 | 송금 요청 · 정산 완료 시 |
| 일정 알림 | 캘린더 이벤트 시작 15분 전 |
| 주간 리포트 | 매주 월요일 오전 9시 |
| 월간 리포트 | 매월 1일 오전 9시 |

## 예산 경고

예산의 몇 %를 썼을 때 경고를 받을지 임계값을 정합니다(기본 85%).

## 그 밖의 설정

- **이메일 알림 빈도**: 즉시 · 하루에 한 번 등
- **소리 · 진동**: 알림이 올 때 소리 · 진동 여부
