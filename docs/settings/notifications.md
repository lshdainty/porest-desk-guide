## 알림 종류별 켜고 끄기

맨 위 **푸시 알림**을 끄면 아래 종류와 상관없이 전부 꺼집니다. 개별로 켜고 끄려면 아래 종류별 스위치를 씁니다.

| 알림 | 오는 시점 |
|---|---|
| 결제 알림 | 결제 예정일 D-1, 결제일 당일 |
| 예산 알림 | 카테고리 예산이 아래 임계값 · 100% 도달 시 |
| 자동 기록 알림 | 반복 거래가 자동으로 기록되었을 때 |
| 더치페이 알림 | 송금 요청 · 정산 완료 시 |
| 일정 알림 | 캘린더 이벤트 시작 15분 전 |
| 주간 리포트 | 매주 월요일 오전 9시 |
| 월간 리포트 | 매월 1일 오전 9시 |

## 예산 알림 임계값

![알림 설정 하단 — 예산 임계값 슬라이더, 방해 금지 시간, 소리·진동, 이메일 알림](/img/screens/settings-notifications-full.png)

예산 사용률이 몇 %를 넘으면 경고 알림을 받을지 **50 ~ 100% 사이에서 슬라이더로 직접 정합니다**(기본값 85%). 100%를 넘어서면 이 임계값과 별개로 "초과" 알림이 한 번 더 옵니다.

## 방해 금지 시간

**방해 금지 사용**을 켜고 시간대를 지정하면, 그 시간에는 알림이 소리 · 진동 없이 화면에만 조용히 표시됩니다(알림 자체가 안 오는 게 아니라 무음 처리됩니다).

## 소리 · 진동

**알림음**(차임 등)을 고르고, **진동**은 모바일에서 따로 켜고 끕니다.

## 이메일 알림

**이메일 받기**를 켜면 계정 이메일로 알림 요약을 받습니다.
