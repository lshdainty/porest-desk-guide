# 카테고리 관리

거래내역에 붙이는 수입 · 지출 카테고리를 관리합니다.

![카테고리 관리 — 상위 카테고리 아래 세부 카테고리를 중첩해 정리합니다("식비" 아래 "외식")](/img/screens/category-list.png)

## 할 수 있는 것

- **새 카테고리 추가**: 이름 · 색상 · 상위 카테고리(있다면)를 지정
- **수정 · 삭제**: 기존 카테고리를 고치거나 지웁니다

카테고리는 [예산](./budget.md) 한도와 [통계](../expense/stats.md) 화면에서도 그대로 쓰입니다.
