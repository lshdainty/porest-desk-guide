# 카테고리 관리

거래내역에 붙이는 수입 · 지출 카테고리를 관리합니다. 카테고리는 [예산](../expense/budget.md) 한도와 [통계](../expense/stats.md) 화면에서도 그대로 쓰입니다.

가입하면 지출 8개(식비 · 카페·간식 · 교통 · 주거·통신 · 생활 · 쇼핑 · 건강 · 문화·여가)와 수입 3개(급여 · 용돈 · 부수입)가 미리 들어 있습니다. 이름은 한국어로 고정이라 언어를 바꿔도 번역되지 않습니다.

## 화면 구성

- **지출 N / 수입 N 탭**: 종류별로 따로 관리합니다(지출 카테고리를 수입 거래에 쓸 수 없고 그 반대도 마찬가지입니다)
- **2단계 구조**: 대분류(최상위) 아래 세부 카테고리를 한 단계까지만 둘 수 있습니다. 하위가 있는 대분류에는 "지출 · 하위 카테고리 있음" 이 붙고, 펼침 화살표로 펼치고 접습니다
- **카테고리 검색**: 이름으로 바로 찾기
- **행의 아이콘**(데스크톱): 대분류에는 **[+]**(하위 추가), 모든 행에 **연필**(수정) · **휴지통**(삭제). 모바일은 행을 누르면 수정 시트가 열립니다

## 카테고리 생성

1. **[+ 추가]** 를 누릅니다 — 데스크톱은 오른쪽 위, 모바일은 검색창 오른쪽에 있습니다. 데스크톱은 대분류 행의 **[+]**(하위 추가)로 그 아래 하위를 바로 만들 수도 있습니다
2. **구분**(지출 · 수입)을 고릅니다
3. **상위 카테고리**를 고릅니다 — "최상위 카테고리로 두기" 면 부모 없는 대분류가 됩니다. 후보는 같은 구분의 대분류뿐입니다
4. **이름**을 입력합니다 — 최대 12자. **같은 구분 · 같은 상위 아래**에 같은 이름이 있으면 "같은 위치에 같은 이름의 카테고리가 있습니다" 로 막힙니다(지출 '이자'와 수입 '이자'는 둘 다 만들 수 있습니다)
5. **색상 · 아이콘**을 고릅니다
6. **[추가]**

:::info[세부 카테고리에만 거래를 붙일 수 있어요]
"식비"처럼 하위 항목을 거느린 상위 카테고리는 분류용일 뿐, 거래를 직접 붙일 수 없습니다. 거래에는 "식비 › 외식"처럼 더 이상 나뉘지 않는 **가장 아래 단계**의 카테고리만 지정할 수 있습니다.
:::

## 순서 바꾸기

행 왼쪽의 **드래그 손잡이(⠿)** 로 **같은 층 안에서** 순서를 바꿉니다 — 대분류끼리, 같은 대분류 아래 하위끼리만 움직입니다. 끌어다 놓는 것으로 다른 대분류 밑으로 옮기지는 못하니, 그럴 땐 수정 창의 **상위 카테고리**를 바꾸세요.

모바일은 평소에 손잡이가 없습니다. 오른쪽 위 **[편집]** 을 누르면 손잡이와 "핸들을 잡고 위·아래로 끌어 순서를 바꿔요. 상위 카테고리끼리·하위 카테고리끼리 이동돼요." 안내가 나오고, 다 옮기면 **[완료]** 를 누릅니다.

## 카테고리 수정

데스크톱은 행의 **연필 아이콘**, 모바일은 행을 누르면 수정 창이 열려 **구분 · 이름 · 색상 · 아이콘**을 바꿀 수 있습니다. **하위 카테고리**라면 **상위 카테고리**도 다른 대분류로 바꿀 수 있습니다 — 옮겨 갈 대분류의 이번 달 예산을 넘기게 되면 "예산 초과 확인" 창이 한 번 더 묻습니다.

:::info[최상위로 올리거나 다른 카테고리 밑으로 넣을 수는 없어요]
- **하위 → 최상위**: 상위 칸에 "최상위로 두기" 가 없습니다. 칸 아래 안내("다른 상위 카테고리로 이동할 수 있어요. 최상위로 올리려면 새 최상위를 만들어 거래를 옮겨 주세요.") 대로 **새 대분류를 만들고**, 원래 하위의 **⇄ 거래 옮기기 → 기존 카테고리로**에서 그 새 카테고리를 고른 뒤, 빈 하위를 지우세요.
- **최상위 → 다른 카테고리의 하위**: 대분류를 고칠 때는 상위 칸이 없습니다. 원하는 대분류 밑에 하위를 새로 만들고, 거래를 옮긴 뒤 원래 대분류를 지우세요.
- 하위 카테고리의 지출 · 수입 구분은 상위와 같아야 합니다.
:::

## 거래 옮기기

수정 창 맨 아래의 **⇄ 거래 옮기기**(데스크톱 · 모바일 모두)는 그 카테고리에 달린 **거래 · 반복 거래 · 분할 항목을 한꺼번에** 다른 카테고리로 옮깁니다.

- **새 하위 만들기** — 하위가 없는 대분류에서 열면 기본으로 선택됩니다. **만들 하위 이름**(예: 강의)만 넣고 **[옮기기]** 를 누르면, 그 이름의 하위를 만들고 거래를 모두 그리로 옮깁니다("○○ 아래에 만들고 거래를 모두 그리로 옮겨요. 그러면 다른 하위도 만들 수 있어요").
- **기존 카테고리로** — 같은 구분의 가장 아래 단계 카테고리 가운데 하나를 골라 모두 옮깁니다. 옮길 곳이 없으면 "옮길 수 있는 카테고리가 없어요. 먼저 하나 만들어주세요" 가 뜹니다.

끝나면 "N건을 옮겼어요" 가 뜹니다.

:::info[거래가 붙어 있으면 하위 카테고리를 만들 수 없어요]
거래(반복 거래 · 분할 항목 포함)가 직접 달린 카테고리는 그 아래에 하위를 만들 수 없습니다 — "거래가 있는 카테고리엔 하위를 만들 수 없어요. 거래·반복 거래를 먼저 옮겨 주세요". 위의 **새 하위 만들기**로 한 번에 풀 수 있습니다.
:::

## 카테고리 삭제

1. 데스크톱은 행의 **휴지통 아이콘**, 모바일은 행을 눌러 연 수정 시트의 **[삭제]** 를 누릅니다
2. **"○○" 카테고리를 삭제할까요?** 에서 **[삭제]** — 예산이 걸려 있으면 "예산이 설정되어 있는 카테고리입니다. 삭제하면 예산도 함께 삭제됩니다." 가 함께 나옵니다
3. 하위 카테고리가 있으면 **"삭제 불가"** 창이 뜹니다 — 하위부터 정리하세요

![카테고리 삭제 확인](/img/screens/category-delete-confirm.png)

:::danger[카테고리를 지워도 거래는 남아요]
카테고리를 삭제해도 그 카테고리로 기록된 거래는 지워지지 않습니다. 대신 그 카테고리는 카테고리 목록 · 거래 입력 · 필터에서 사라져 새 거래에는 더 고를 수 없고, 걸려 있던 **예산도 모든 달에서 함께 삭제**됩니다. 이미 쓴 거래의 분류를 옮기고 싶다면 지우기 전에 **⇄ 거래 옮기기**로 다른 카테고리에 옮겨 두세요. 이름만 바꾸려면 삭제 대신 **수정**을 쓰면 기존 거래의 분류가 그대로 유지됩니다.
:::
