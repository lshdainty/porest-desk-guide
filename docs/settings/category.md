# 카테고리 관리

거래내역에 붙이는 수입 · 지출 카테고리를 관리합니다. 카테고리는 [예산](../expense/budget.md) 한도와 [통계](../expense/stats.md) 화면에서도 그대로 쓰입니다.

## 화면 구성

- **지출 / 수입 탭**: 종류별로 따로 관리합니다(지출 카테고리를 수입 거래에 쓸 수 없고 그 반대도 마찬가지입니다)
- **드래그 손잡이(⠿)**: 순서를 바꾸거나, 다른 카테고리 위로 끌어놓아 하위 카테고리로 옮길 수 있습니다
- **펼침 화살표**: 하위 카테고리가 있는 항목을 펼치고 접습니다
- **카테고리 검색**: 이름으로 바로 찾기

## 카테고리 생성

1. 오른쪽 위 **[+ 추가]** 를 누릅니다(하위 카테고리를 바로 만들고 싶다면 부모 행의 **[+]** 를 누릅니다)
2. **구분**(지출 · 수입)을 고릅니다
3. **상위 카테고리**를 고릅니다 — 비워두면(최상위 카테고리로 두기) 부모 없는 대분류가 됩니다
4. **이름**을 입력합니다(최대 12자)
5. **색상 · 아이콘**을 고릅니다
6. **[추가]**

:::info[세부 카테고리에만 거래를 붙일 수 있어요]
"식비"처럼 하위 항목을 거느린 상위 카테고리는 분류용일 뿐, 거래를 직접 붙일 수 없습니다. 거래에는 "식비 › 외식"처럼 더 이상 나뉘지 않는 **가장 아래 단계**의 카테고리만 지정할 수 있습니다.
:::

## 카테고리 수정

각 행의 **연필 아이콘**을 누르면 추가할 때와 같은 폼이 열려 이름 · 색상 · 아이콘 · 상위 카테고리를 바꿀 수 있습니다.

모바일에서는 행을 누르면 같은 내용의 수정 시트가 아래에서 올라옵니다. 데스크톱에는 없는 **[⇄ 거래 옮기기]** 도 여기서 볼 수 있습니다.

:::info[거래가 붙어 있으면 하위 카테고리를 만들 수 없어요]
이미 거래가 연결된 카테고리는 그 아래에 세부 카테고리를 새로 만들 수 없습니다. 그 카테고리 안의 거래를 **[거래 옮기기]** 로 다른 카테고리에 옮긴 뒤에야 하위 분류를 만들 수 있습니다.
:::

## 카테고리 삭제

1. 행의 **휴지통 아이콘**을 누릅니다
2. **"OO 카테고리를 삭제할까요?"** 확인 창에서 **[삭제]**

![카테고리 삭제 확인](/img/screens/category-delete-confirm.png)

:::danger[이미 쓰인 카테고리를 삭제하면 그 거래들은 "미분류"가 됩니다]
카테고리를 삭제해도 그 카테고리로 이미 기록된 과거 거래는 지워지지 않고 남습니다. 다만 **그 거래들의 카테고리는 곧바로 "미분류"로 바뀝니다** — 삭제된 카테고리 이름이 계속 표시되는 게 아닙니다. 자주 쓰던 카테고리를 지우면 지난 통계 · 예산 집계의 분류가 그만큼 흐트러질 수 있으니, 정말 더 이상 쓰지 않을 카테고리인지 확인하고 지우세요. 이름만 바꾸고 싶다면 삭제 대신 위의 **수정**을 쓰면 기존 거래의 분류가 그대로 유지됩니다.
:::
