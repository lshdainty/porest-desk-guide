# 데이터 내보내기 · 가져오기

![데이터 내보내기 — 기간과 데이터 종류(거래내역·자산·예산·카테고리·메모·캘린더·할일)를 골라 CSV·Excel·JSON으로 내려받습니다](/img/screens/settings-data-transfer.png)

## 내보내기

거래내역뿐 아니라 자산 · 예산 · 카테고리 · 메모 · 캘린더 일정 · 할 일까지, 원하는 데이터 종류와 기간을 골라 CSV · Excel · JSON 형식으로 내려받습니다.

## 가져오기

다른 가계부 앱에서 쓰던 CSV 파일을 Desk 형식에 맞게 매핑해 한 번에 불러올 수 있습니다.
