# 계좌 · 카드 관리

가계부와 자산 화면에서 쓰일 계좌 · 카드 · 투자 자산을 등록하고 관리합니다.

## 할 수 있는 것

- **새 자산 등록**: 이름 · 종류(계좌 · 신용카드 · 투자 등) · 시작 잔액을 입력
- **신용카드는 추가로**: 결제일, 결제 계좌, 한도, 연회비 실적 조건을 설정
- **잔액 수정**: 실제 잔액과 다르면 직접 맞춰 넣을 수 있습니다
- **삭제**: 더 이상 쓰지 않는 자산 제거

:::warning[신용카드는 결제일을 꼭 등록하세요]
결제일을 비워둬도 저장은 되지만, 그러면 **자동결제가 전혀 실행되지 않습니다** — [지금 결제](../asset/card.md#결제일을-등록하지-않으면-어떻게-되나요) 버튼을 직접 눌러야만 정산됩니다.
:::

:::tip[잔액 수정은 신중하게]
잔액을 손으로 맞추면 그 순간 이전의 사용 기록은 이후 계산에서 빠집니다. 자세한 원리는 [자산 개요](../asset/overview.md#잔액은-어떻게-계산되나요)에서 설명합니다.
:::
