# 저축목표

모으고 싶은 금액을 목표로 정해 두고, 지금까지 모은 금액으로 진행률을 봅니다. 만든 목표는 [자산](../asset/overview.md) 화면의 **저축 목표**에도 나옵니다 — 거기서는 보기만 하고, 만들고 고치는 건 이 화면에서 합니다.

- **데스크톱**: 위쪽 바의 톱니바퀴(설정) → 왼쪽 목록 **저축 목표**. 자산 화면 저축 목표의 **관리 ›** 로도 옵니다
- **모바일(웹 · 앱)**: **전체 → 돈 관리 → 저축 목표** 또는 **전체 → 설정 → 데이터 관리 → 저축 목표**. 자산 화면 저축 목표의 **관리 ›** 로도 옵니다

## 화면 구성

- **전체 진행률** — 모든 목표의 모은 금액 합 / 목표 금액 합과 %. 목표가 하나 이상 있을 때만 나옵니다
- **목표 목록 · N개**와 **[+ 목표 추가]**
- 목표마다 아이콘 · 이름 · 목표일(연.월, 예: 2026.12 — 없으면 "기한 없음") · 모은 금액 / 목표 금액 · % · 막대. 목표를 채우면 이름 옆에 **달성**(앱은 "달성!")이 붙습니다
- 목록은 **먼저 만든 목표부터** 나옵니다. 순서를 바꾸는 기능은 없습니다
- 목표가 하나도 없으면 "아직 저축 목표가 없어요. ‘목표 추가’로 시작해보세요."

[금액 가리기](./account.md#금액-가리기)에서 **자산 → 저축목표**를 켜면 자산 화면의 저축 목표와 **앱**의 이 화면 금액이 가려집니다. 웹의 이 설정 화면은 아직 가려지지 않습니다.

## 목표 생성

1. **[+ 목표 추가]**
2. **목표 이름**을 씁니다 — 필수, **최대 12자**(웹은 12자에서 더 입력되지 않고, 앱은 넘기면 "이름은 12자 이내로 입력해 주세요." 와 함께 [추가] 가 막힙니다)
   - 이미 있는 목표와 같은 이름이면 입력하는 동안 "같은 이름의 목표가 이미 있어요." 가 뜨고 저장되지 않습니다
   - 영문은 대소문자만 달라도(Trip · trip) 같은 이름으로 봅니다 — 저장할 때 "같은 이름의 목표가 있어요. 뒤에 1, 2를 붙여 구분해 주세요" 로 막힙니다
   - 지운 목표의 이름은 다시 쓸 수 있습니다
3. **목표 금액**(필수)과 **현재 모은 금액**(비우면 0원)을 씁니다 — 둘 다 **100억 원까지**, 숫자만 들어갑니다
   - **모은 금액은 목표 금액보다 클 수 없습니다** — 웹은 "현재 금액이 목표보다 클 수 없어요" 가 뜨고, 앱은 [추가] 가 눌리지 않습니다
   - 웹에서 목표 금액을 비우고 누르면 "목표 금액을 입력해 주세요", 이름을 비우면 "목표 이름을 입력해 주세요" 가 뜹니다(앱은 둘 다 채워야 [추가] 가 눌립니다)
4. 필요하면 **목표일**(선택 · 앱은 "마감일"), **아이콘**(기본은 돼지저금통), **색상**(10가지)을 고릅니다. 맨 위 미리보기에 이름 · 목표일 · % · 금액이 입력하는 대로 바뀝니다
5. **[추가]**

목표일은 날짜로 고르지만 목록에는 **연 · 월**만 보이고, 날짜가 지나도 알림이나 상태 변화는 없습니다. 앱에서는 목표일을 **2030년 1월 1일까지만** 고를 수 있으니, 그보다 먼 날짜는 웹에서 정하세요.

:::warning["현재 모은 금액"은 계좌와 자동으로 연동되지 않아요]
목표를 계좌와 연결하는 칸이 없습니다. "현재 모은 금액"은 직접 적는 숫자라서, 실제로 통장에 돈을 넣어도 진행률이 저절로 오르지 않습니다 — 저축할 때마다 아래 [목표 수정](#목표-수정)에서 금액을 고쳐 주세요.
:::

## 목표 수정

데스크톱은 목표 카드의 **연필** 아이콘, 모바일은 목표를 누르거나 왼쪽으로 밀어 **[수정]** 을 누릅니다. **저축 목표 수정** 창은 추가할 때와 같아서 이름 · 목표 금액 · 현재 모은 금액 · 목표일 · 아이콘 · 색상을 모두 바꿀 수 있습니다. 저장 버튼은 데스크톱이 **[저장]**, 모바일이 **[수정]** 입니다.

- **현재 모은 금액**에는 이번에 넣은 돈이 아니라 **지금까지 모은 총액**을 적습니다
- 목표일을 없애려면 날짜 칸을 비웁니다(앱은 칸 오른쪽 **×**)

:::info[목표를 채우면 "달성"이 붙어요]
모은 금액이 목표 금액에 닿으면 이름 옆에 **달성**(앱은 **달성!**)이 붙고, 자산 화면에도 똑같이 보입니다. 나중에 모은 금액을 줄이거나 목표 금액을 올리면 다시 사라집니다. 퍼센트는 반올림해 보여 주므로, 거의 다 모았을 때 100%로 보여도 아직 **달성**이 아닐 수 있습니다. 달성하거나 목표일이 지나도 따로 알림은 오지 않습니다.
:::

## 목표 삭제

데스크톱은 목표 카드의 **휴지통** 아이콘, 모바일은 목표를 왼쪽으로 밀어 **[삭제]** 를 누릅니다(수정 창에는 삭제 버튼이 없습니다). **저축 목표 삭제** 창의 **"제주도 여행" 목표를 삭제할까요? 이 작업은 되돌릴 수 없어요.** 에서 **[삭제]** 를 누릅니다.

:::danger[되돌릴 수 없습니다]
삭제한 목표는 되살릴 수 없습니다. 목표에는 모은 금액 숫자 하나만 있고 입금 내역은 따로 쌓이지 않으므로, 지우면 그 숫자도 함께 사라집니다. 목표는 계좌와 연결돼 있지 않아서 지워도 **계좌 잔액이나 거래 기록에는 아무 영향이 없습니다**.
:::
