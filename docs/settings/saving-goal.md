# 저축목표

모으고 싶은 목표 금액을 정해두고 진행 상황을 추적합니다. [자산 개요](../asset/overview.md)에서도 진행률을 확인할 수 있습니다.

<TabItem value="desktop" label="데스크톱">

</TabItem>
<TabItem value="mobile" label="모바일">

![저축 목표 — 목표 금액과 지금까지 모은 금액으로 진행률을 표시합니다](/img/screens/mobile-settings-saving-goal.png)

</TabItem>
</Tabs>

## 목표 생성

1. **[+ 목표 추가]**
2. **목표 이름**, **목표 금액**, **현재 모은 금액**을 입력합니다
3. 필요하면 **목표일**(선택), 아이콘 · 색상을 정합니다
4. **[추가]**

<TabItem value="desktop" label="데스크톱">

![저축 목표 추가 — 목표 이름·금액과 현재 모은 금액을 직접 입력합니다](/img/screens/settings-saving-goal-add-form.png)

</TabItem>
<TabItem value="mobile" label="모바일">

![저축 목표 추가 — 목표 이름·금액과 현재 모은 금액을 직접 입력합니다](/img/screens/mobile-settings-saving-goal-add-form.png)

</TabItem>
</Tabs>

:::warning["현재 모은 금액"은 계좌와 자동으로 연동되지 않아요]
목표 금액과 달리 **연결할 계좌를 지정하는 기능은 없습니다.** "현재 모은 금액"은 그냥 숫자를 직접 입력하는 항목이라, 실제로 계좌에 돈을 더 넣어도 진행률이 저절로 올라가지 않습니다 — 저축할 때마다 이 화면에서 직접 금액을 고쳐줘야 진행률이 맞습니다.
:::

목표 카드의 **연필 아이콘**을 누르면 추가할 때와 같은 폼이 열려 이름 · 금액 · 모은 금액 · 목표일을 모두 바꿀 수 있습니다.

## 목표 삭제

목표 카드의 **휴지통 아이콘**을 누르고 확인 창에서 **[삭제]** 를 누릅니다.

<Tabs groupId="device">
<TabItem value="desktop" label="데스크톱">

![저축 목표 삭제 확인 — 되돌릴 수 없습니다](/img/screens/settings-saving-goal-delete-confirm.png)

</TabItem>
<TabItem value="mobile" label="모바일">

![저축 목표 삭제 확인 — 되돌릴 수 없습니다](/img/screens/mobile-settings-saving-goal-delete-confirm.png)

</TabItem>
</Tabs>

:::danger[되돌릴 수 없습니다]
"이 작업은 되돌릴 수 없어요" — 삭제한 목표와 그동안의 진행 기록은 복구할 수 없습니다. 목표를 지워도 **연결된 계좌나 그 계좌의 거래 기록에는 아무 영향이 없습니다** — 애초에 계좌와 연동되어 있지 않기 때문입니다.
:::
