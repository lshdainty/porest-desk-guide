# 표시 설정

![표시 설정 — 테마, 표시 기준 지역, 언어(한국어/English), 기본 통화를 한 화면에서 관리](/img/screens/settings-display.png)

## 테마

라이트 · 다크 · 시스템 설정 따라가기 중 고릅니다.

## 표시 기준 지역

Desk 내부적으로는 모든 시간을 표준시(UTC)로 관리하고, 화면에는 여기서 정한 지역의 시간대로 바꿔 보여줍니다. 예를 들어 한국에서 쓰다가 여행 중 미국에서 이 설정을 바꾸면, 그 이후 입력하는 시간은 현지 시간 기준으로 기록됩니다.

## 언어

한국어 · 영어 중 고릅니다.

## 기본 통화

KRW · USD · EUR · JPY 중 고릅니다. 가계부 금액 표시에 쓰이는 기본 통화입니다.
