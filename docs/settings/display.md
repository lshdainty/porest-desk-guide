# 표시 설정

화면 모양과 기본값을 정합니다. 설정마다 **저장되는 범위**가 다르니 각 절 끝의 안내를 봐 주세요 — 테마 · 언어는 **이 기기에만**, 기준 지역 · 기본 통화는 **계정 전체**에 적용됩니다.

## 테마

**라이트**(밝은 배경) · **다크**(어두운 배경) · **시스템**(휴대폰 · 컴퓨터 설정을 따라감) 중 고릅니다. 데스크톱은 화면 맨 위 바의 **해 · 달 아이콘**으로도 같은 세 가지를 바로 바꿀 수 있습니다.

→ **이 기기(브라우저 · 앱)에만** 저장됩니다. 다른 기기에서는 따로 정해 주세요.

## 기준 지역

**'오늘'이 며칠인지를 이 지역 기준으로 계산**합니다 — 홈의 '오늘', 통계 · 예산의 하루 경계 같은 것들입니다. 화면에 보이는 **시각은 이 설정이 아니라 지금 쓰는 기기의 시간대**를 따릅니다(화면 안내 그대로 "화면의 시간은 기기 시간대로 보여요").

거래나 일정에 적은 시각은 입력한 그대로 저장되므로, 이 설정을 바꿔도 이미 적은 시각은 바뀌지 않습니다. 해외에 오래 머물며 그곳 날짜로 하루를 세고 싶을 때 바꾸세요. 일정 알림도 이 지역 기준으로 시각을 계산합니다.

대한민국 (서울)부터 UTC (협정 세계시)까지 21개 지역 중 고르고, 처음 값은 가입할 때 고른 지역(보통 대한민국 (서울))입니다.

→ **계정**에 저장되어 모든 기기에 똑같이 적용됩니다.

## 언어

- **웹**: 한국어 · English
- **앱**: 시스템(휴대폰 언어를 따라감) · 한국어 · English

카테고리 이름처럼 **내가 만든 이름은 번역되지 않습니다** — 가입할 때 들어 있던 기본 카테고리도 한국어 그대로입니다.

→ **이 기기에만** 저장됩니다.

## 기본 통화

**₩ 대한민국 원(KRW) · $ 미국 달러(USD) · € 유로(EUR) · ¥ 일본 엔(JPY)** 중 고릅니다. 여기서 고른 통화가 **새 계좌 · 카드 · 투자를 등록하거나 새 거래를 추가할 때 통화 칸에 먼저 골라져 있습니다** — 값을 강제로 바꾸는 게 아니라 매번 고르는 수고를 덜어 주는 기본값입니다. 이미 등록된 자산 · 거래의 통화는 바뀌지 않습니다.

→ **계정**에 저장되어 모든 기기에 똑같이 적용됩니다.

:::info[없는 설정]
주 시작 요일 · 숫자 형식 · 화면 밀도를 바꾸는 설정은 없습니다.
:::
