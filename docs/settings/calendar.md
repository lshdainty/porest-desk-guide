## 라벨 생성

1. **[+ 라벨 추가]**
2. **이름**(최대 12자)과 **색상**을 정합니다
3. **[추가]** — 새 라벨은 [캘린더](../calendar/calendar.md)에서 바로 고를 수 있습니다

## 라벨 삭제

행의 **휴지통 아이콘**을 누르고 확인 창에서 **[삭제]** 를 누릅니다.

![라벨 삭제 확인 — 이 라벨이 붙은 일정은 라벨 없음 상태가 됩니다](/img/screens/settings-calendar-label-delete-confirm.png)

:::danger[삭제하면 그 라벨이 붙어있던 일정은 "라벨 없음"이 됩니다]
확인 창에 그대로 적혀 있듯, 라벨을 삭제해도 **일정 자체는 지워지지 않습니다.** 다만 그 라벨이 붙어 있던 모든 일정은 라벨이 없는 상태로 바뀝니다 — [카테고리 삭제](./category.md#카테고리-삭제)가 관련 거래를 "미분류"로 바꾸는 것과 같은 방식입니다.
:::

## 캘린더 공유

내 캘린더를 다른 사람과 공유하거나, 공유받은 캘린더를 내 화면에 함께 표시할지 관리합니다.

:::info["다중 캘린더 공유"는 Porest Pro 기능입니다]
Free · Pro 요금 비교표에는 "다중 캘린더 공유"가 Pro 전용으로 표시됩니다. 정확히 몇 개까지가 Free의 기본 공유 범위인지는 이 문서에서 다루지 않으니, 여러 캘린더를 동시에 공유해야 한다면 [구독](../subscription/subscription.md) 화면에서 현재 플랜의 제한을 확인하세요.
:::

초대코드로 참여한 사람은 기본적으로 **편집 가능** 권한을 갖습니다(일정을 만들고 지울 수 있음). 조회만 하게 하고 싶다면 멤버 목록에서 그 사람의 권한을 **읽기 전용**으로 낮춰주세요.

:::info[공유 캘린더 멤버 목록]
공유 캘린더의 멤버 목록을 열어보면, 읽기 전용으로 참여한 사람도 다른 멤버들의 이메일을 볼 수 있습니다.
:::

:::warning[캘린더를 삭제하면]
공유하던 캘린더 자체를 삭제하면 그 안의 일정은 지워지지 않고 소유자의 기본 캘린더로 옮겨지며, 공유받던 사람들은 접근이 끊깁니다.
:::
