# 캘린더 라벨 · 공유

설정에는 캘린더 메뉴가 두 개 있습니다.

- **캘린더 라벨** — 일정에 붙이는 라벨을 관리합니다(설정의 **태그 · 라벨** 묶음)
- **캘린더 관리·공유** — 캘린더를 새로 만들고 다른 사람과 함께 씁니다(설정의 **공유** 묶음). [캘린더](../calendar/calendar.md) 화면의 캘린더 목록 맨 아래 **캘린더 관리 · 공유 설정** 으로도 들어옵니다

## 캘린더 라벨

"모든 캘린더에서 공용으로 사용되는 라벨이에요. 일정 등록 시 선택할 수 있어요." — 라벨마다 색과 이름, **"N건에 사용 중"** 이 보입니다. 라벨을 붙인 일정은 캘린더에 [라벨 색으로](../calendar/calendar.md#일정-생성) 보입니다.

라벨은 **나만 쓰는 분류**입니다. 공유 캘린더의 다른 멤버는 내 일정에 붙은 라벨 이름 · 색을 볼 수는 있지만, 내 라벨을 자기 일정에 고를 수는 없습니다.

## 라벨 생성

1. **[+ 라벨 추가]**
2. **이름**과 **색상**(10가지)을 정합니다. 위의 **미리보기**에 붙을 모양이 보입니다
   - 이름은 **12자까지** — 넘으면 "이름은 12자 이내로 입력해 주세요.", 비우면 "라벨 이름을 입력해 주세요."
   - 같은 이름이 이미 있으면 "같은 이름의 라벨이 이미 있어요."
3. **[추가]** — 새 라벨은 [일정 추가](../calendar/calendar.md#일정-생성) 창에서 바로 고를 수 있습니다

## 라벨 수정

데스크톱은 라벨 행(오른쪽 화살표)을, 모바일은 행을 누르면 **라벨 수정** 창이 열려 이름 · 색상을 바꿉니다. 모바일에서는 행을 왼쪽으로 밀어 수정 · 삭제 버튼을 꺼낼 수도 있습니다. 이름이나 색을 바꾸면 그 라벨을 붙인 일정에 바로 반영됩니다.

## 라벨 삭제

행의 **휴지통 아이콘**(모바일은 행을 밀어 **[삭제]**)을 누르면 **"○○" 라벨을 삭제할까요? 이 라벨이 지정된 일정은 라벨 없음 상태가 됩니다.** 확인 창이 뜨고, **[삭제]** 를 누르면 라벨 목록과 일정 추가 창의 라벨 목록에서 사라집니다. 일정 자체는 지워지지 않습니다.

![라벨 삭제 확인](/img/screens/settings-calendar-label-delete-confirm.png)

:::warning[이미 붙여 둔 일정에는 라벨이 남아 보여요]
확인 창의 안내와 달리, 지금은 **그 라벨을 이미 붙여 둔 일정에 지운 라벨의 이름과 색이 그대로 남아 보입니다.** 떼려면 그 일정을 열어 [일정 수정]에서 라벨을 **라벨 없음**(또는 다른 라벨)으로 바꿔 저장하세요.
:::

## 캘린더 공유

**캘린더 관리·공유**는 "캘린더를 만들고 가족·친구를 초대해 일정을 함께 관리할 수 있어요." 화면입니다.

- **내 캘린더 · N** — 내가 만든 캘린더들. 처음 만들어진 기본 캘린더에는 **기본** 표시가 붙고, 줄마다 "나만 사용" 또는 "멤버 N명" 이 보입니다. 오른쪽 **[+ 캘린더 추가]** 로 새 캘린더를 만듭니다(이름 — 예: 가족, 업무, 운동 일정 — 과 색상)
- **공유받은 캘린더 · N** — 초대받아 들어간 캘린더와 내 권한(**편집 가능** · **읽기 전용**)
- **초대 코드로 참여** — **[참여]** 를 누르고 받은 초대 코드를 넣으면 "캘린더에 참여했어요" 가 뜹니다. 코드가 틀리면 "초대 코드를 확인해 주세요". 초대 코드로 들어온 사람은 처음에 **편집 가능** 권한을 받습니다

캘린더 줄을 누르면 **"○○ · 관리"** 창이 열립니다.

### 내가 만든 캘린더를 관리할 때

- **이름 · 색상**을 바꾸고 **[저장]**
- **초대 코드** — 복사 아이콘으로 "초대 코드를 복사했어요", 새로고침 아이콘으로 **새 코드**를 만듭니다("초대 코드를 새로 만들었어요" — 예전 코드로는 더 이상 들어올 수 없습니다). "이 코드를 공유하면 다른 사람이 캘린더에 참여할 수 있어요."
- **멤버** — 이름 · 이메일과 권한이 보입니다. 다른 멤버의 권한을 **편집 가능 · 읽기 전용** 중에서 바꾸거나, 휴지통 아이콘으로 **내보내기**("○○ 님을 캘린더에서 내보내시겠어요?")를 합니다. 권한마다 할 수 있는 일은 [캘린더 → 라벨과 공유](../calendar/calendar.md#라벨과-공유)의 표를 보세요
- **[캘린더 삭제]** — 기본 캘린더에는 없습니다

### 공유받은 캘린더를 열었을 때

멤버 목록(이름 · 이메일 · 권한)만 보입니다. 이름을 바꾸거나 멤버를 관리할 수 없고, **스스로 나가는 버튼도 없습니다** — 더 쓰지 않으려면 소유자에게 내보내 달라고 하세요. 화면에서만 치우고 싶다면 캘린더 목록에서 그 캘린더를 끄면 됩니다.

:::info[공유 캘린더 멤버 목록]
공유 캘린더의 멤버 목록을 열어보면, 읽기 전용으로 참여한 사람도 다른 멤버들의 이메일을 볼 수 있습니다.
:::

:::warning[캘린더를 삭제하면]
[캘린더 삭제]를 누르면 **"○○" 캘린더를 삭제할까요? 일정은 기본 캘린더로 이동하고 모든 멤버의 접근 권한이 사라집니다.** 가 뜨고, **[영구 삭제]** 로 확정합니다. 그 캘린더의 일정은 지워지지 않고 **소유자의 기본 캘린더로** 옮겨집니다 — 다른 멤버가 만든 일정도 함께 옮겨지고, 멤버들은 더 이상 볼 수 없습니다.
:::
