# 프리셋

자주 입력하는 거래(점심 · 커피 · 교통비, 비상금 넣기 같은 이체 등)를 프리셋으로 저장해 두면, [거래 추가](../expense/transactions.md#프리셋으로-빠르게-넣기) 창 맨 위 **프리셋 불러오기**에서 한 번 눌러 칸을 채울 수 있습니다. 프리셋은 **칸만 채울 뿐 거래를 바로 만들지 않습니다** — 채워진 값을 확인하고 **[추가]** 를 눌러야 저장됩니다.

- **데스크톱**: 위쪽 바의 톱니바퀴 → 설정 왼쪽 목록의 **프리셋 관리**
- **모바일(웹 · 앱)**: **전체 → 개인화 → 프리셋**, 또는 **설정 → 데이터 관리 → 프리셋 관리**

## 화면 구성

- **요약**: **저장된 프리셋** 개수 · **누적 사용** 횟수 · **지출 / 수입 / 이체** 개수(앱은 제목이 "지출 / 수입" 으로만 보이지만 숫자는 이체까지 셋입니다)
- **정렬**: **사용 많은 순**(처음 선택) · **최근 사용**(한 번도 안 쓴 프리셋은 맨 뒤) · **이름순**, 오른쪽에 **[+ 프리셋 추가]**
- **목록의 한 줄**
  - 이름 옆에 **이체** · **수입** 배지(지출은 배지 없음)와, 고정 금액이 없으면 **금액 비움** 배지
  - 아래 줄은 카테고리(이체는 "출금 계좌 → 입금 계좌") · 기본 내역이고, 데스크톱은 계좌도 붙습니다
  - 오른쪽에 고정 금액(없으면 —)과 사용 횟수
- **행에서 할 수 있는 일**: 데스크톱은 행의 **연필**(수정) · **휴지통**(삭제) 아이콘. 모바일은 행을 누르면 **프리셋 상세**(유형 · 카테고리 · 계좌·카드 · 기본 내역 · 메모, 이체는 출금 계좌 · 입금 계좌 · 수수료 · 이자)가 열려 **[삭제] · [수정]** 을 고르고, 왼쪽으로 밀면 **[수정] · [삭제]** 가 나옵니다

**사용 횟수**는 거래 추가 창에서 프리셋을 불러와 **적용됨** 표시가 붙은 채로 거래를 저장할 때마다 1씩 늘고, 그 시각이 **최근 사용**이 됩니다. **[해제]** 를 눌렀거나, 웹에서 불러온 뒤 카테고리(대분류) · 결제 수단 · 계좌 · 할부 · 통화를 바꿔 표시가 풀린 채 저장한 거래는 세지 않습니다.

[금액 가리기](./account.md#금액-가리기)의 **기타** 탭에서 **프리셋**을 고르면 앱의 프리셋 목록 금액이 가려집니다. 웹의 프리셋 화면과 앱의 상세 창에는 아직 적용되지 않습니다.

## 프리셋 생성

1. **[+ 프리셋 추가]** 를 누르면 **프리셋 추가** 창이 열립니다
2. 칸을 채웁니다

| 칸 | 설명 |
|---|---|
| **유형** | 지출 · 수입 · **이체**. 이체는 [아래](#이체-프리셋)에서 따로 다룹니다 |
| **프리셋 이름** | **12자까지**(아래에 "N/12"). 이미 있는 이름이면 "같은 이름의 프리셋이 이미 있어요." 가 뜨고 저장되지 않습니다. 지운 프리셋의 이름은 다시 쓸 수 있습니다 |
| **카테고리** | 꼭 골라야 합니다. 대분류를 누르면 첫 세부 카테고리가 골라지고, 아래 칸에서 다른 세부로 바꿉니다 |
| 기본 내역 | 불러올 때 **거래처** 칸에 들어갈 값 |
| 결제 수단 | 현금 · 카드 · 계좌이체 · 기타 |
| 계좌 · 카드 | 여기서는 결제 수단과 상관없이 모든 자산이 나옵니다. 결제 수단과 짝이 맞지 않는 계좌(예: 결제 수단 '현금'에 은행 계좌)를 고르면, 웹 거래 추가 창에서는 불러올 때 계좌 칸이 비워집니다 |
| 메모 | 불러올 때 거래의 **메모** 칸에 들어갈 값입니다(프리셋 설명이 아닙니다). 웹은 계좌 · 카드 아래, 앱은 기본 내역 바로 아래에 있습니다 |
| **고정 금액 사용** | 켜면 **고정 금액** 칸(1원 ~ 100억 원)이 나오고, 불러올 때마다 그 금액이 채워집니다. 꺼 두면 금액 없이 저장되고 불러올 때 금액 칸이 비어 있습니다 — "꺼두면 불러올 때 금액이 비어있어요. 매번 다른 금액일 때 편해요." |

3. **[추가]** — 이름과 카테고리(이체는 두 계좌)가 있고, 고정 금액을 켰다면 금액까지 있어야 눌립니다

## 이체 프리셋

유형에서 **[이체]** 를 고르면 카테고리 · 기본 내역 · 결제 수단 · 계좌·카드 대신 **출금 계좌 · 입금 계좌 · 수수료 (선택)** 를 미리 정해 둡니다(메모는 그대로 있습니다). 늘 같은 두 계좌 사이에서 금액만 바꿔 옮길 때(비상금 넣기, 생활비 통장으로 이체 등) 편합니다.

- [거래 추가의 이체](../expense/transactions.md#이체--내-계좌-사이에서-돈-옮기기)와 규칙이 같습니다 — **카드는 목록에 없고**("반복·프리셋 이체에는 카드를 고를 수 없어요. 카드 결제는 자동 결제가 맡아요"), 입금 목록에서는 출금으로 고른 계좌가 빠집니다
- **이자** 칸은 **받는 계좌가 대출**이고 **고정 금액 사용**을 켰을 때만 나타납니다. 금액이 매번 다르면 이자도 매번 달라지므로, 고정 금액을 끄면 적어 둔 이자도 지워집니다. 수수료는 고정 금액과 상관없이 저장됩니다

:::info[금액을 비워둔 채로 저장할 수 있어요]
**고정 금액 사용**을 꺼두면 금액 없이 저장됩니다 — 금액 검사는 프리셋을 저장할 때가 아니라 **불러와서 이체를 저장할 때** 합니다. 목록에는 "금액 비움"으로 표시되고, 불러오면 두 계좌 · 수수료 · 메모만 채워진 채 금액 칸이 비어서 열립니다. 매달 넣는 금액이 달라지는 저축 이체에 맞는 방식입니다.
:::

## 거래 추가에서 불러오기

[거래 추가](../expense/transactions.md#프리셋으로-빠르게-넣기) 창 맨 위 **프리셋 불러오기**에는 **지금 보고 있는 탭(지출 · 수입 · 이체)의 프리셋만** 사용 많은 순으로 **8개까지** 칩으로 뜹니다 — 종류가 다른 프리셋을 잘못 눌러 엉뚱한 값이 채워지지 않게 하기 위해서입니다. 고정 금액 프리셋은 칩에 금액이 짧게 붙습니다. 거래를 수정할 때는 이 줄이 나오지 않습니다.

칩을 누르면

- 카테고리 · 계좌·카드 · 거래처(기본 내역) · 결제 수단 · 메모가 프리셋 값으로 **바뀝니다**(이체는 두 계좌 · 수수료 · 이자). 프리셋에 없는 칸은 비워지고, 날짜 · 시간은 그대로입니다
- **금액**은 고정 금액일 때만 채워지고, 아니면 **비워집니다** — 먼저 적어 둔 금액도 지워지니 금액은 프리셋을 고른 뒤에 넣으세요
- 제목 옆에 **적용됨**, 아래에 "프리셋 값이 채워졌어요. 금액·내역만 수정해서 저장하세요." 와 **[해제]** 가 나옵니다. [해제]는 채운 값을 되돌리지 않고 표시만 지웁니다(그 거래는 사용 횟수에 세지 않습니다)
- **앱**은 고정 금액 프리셋을 불러오면 금액 칸이 **프리셋 잠금**으로 잠깁니다. [해제]를 눌러도 풀리지 않으니, 다른 금액을 넣으려면 창을 닫고 다시 여세요. 웹은 채워진 금액을 그대로 고칠 수 있습니다

지금 탭에 프리셋이 없으면 "저장된 프리셋이 없어요. 자주 쓰는 내역을 입력 후 “현재 입력값 저장”을 눌러보세요." 가 나옵니다. 칩 끝의 **설정 → 프리셋 관리** 는 프리셋이 더 있다는 표시일 뿐 누르는 버튼이 아닙니다 — 앱은 같은 종류가 8개를 넘을 때, 웹은 다른 탭의 프리셋까지 합쳐 칩보다 많을 때 붙습니다.

### 지금 입력한 값을 프리셋으로 저장

같은 줄 오른쪽 **[+ 현재 입력값 저장]** 을 누르면 **프리셋으로 저장** 창이 열립니다. 금액과 카테고리(이체는 두 계좌)를 채워야 눌립니다.

1. **프리셋 이름**을 적습니다 — 처음엔 거래처가 채워져 있습니다(이체는 빈칸)
2. 금액까지 담으려면 **금액도 함께 저장**(앱은 "금액 잠금 — 적용 시 N원 자동 채움")을 켭니다. **처음엔 꺼져 있어서** 그대로 저장하면 금액 없는 프리셋이 됩니다. 대출 상환 이체의 이자도 이걸 켰을 때만 함께 저장됩니다
3. **[저장]** — 카테고리 · 계좌 · 거래처 · 결제 수단 · 메모(이체는 두 계좌 · 수수료 · 메모)는 지금 입력한 그대로 저장됩니다

이 창은 설정의 [프리셋 추가](#프리셋-생성)와 달리 **이름 12자 제한과 같은 이름 검사를 미리 하지 않습니다.** 같은 이름이면 저장할 때 "같은 이름의 프리셋이 있어요. 뒤에 1, 2를 붙여 구분해 주세요" 가 뜨고, 12자가 넘는 이름은 저장되지만 나중에 웹 [수정](#프리셋-수정) 창에서는 12자 이내로 줄여야 저장됩니다.

:::warning[앱에서 저장이 안 될 때]
- **계좌 · 카드를 비워 둔 지출 · 수입**은 [저장]을 눌러도 아무 일도 일어나지 않습니다(안내 없이 창이 그대로 남습니다). 계좌를 고른 뒤 저장하세요
- 이름 칸이 빈 채로 열리면(이체는 늘 빈칸) 이름을 적어도 [저장]이 흐린 채로 남습니다. **금액 잠금** 체크를 한 번 눌렀다 되돌리면 눌리게 됩니다
:::

## 프리셋 수정

데스크톱은 행의 **연필 아이콘**, 모바일은 행을 밀어서 나오는 **[수정]** 이나 프리셋 상세의 **[수정]** 을 누릅니다. 추가할 때와 같은 폼이 **프리셋 수정** 이라는 제목으로 열려, 유형 · 이름 · 카테고리 · 기본 내역 · 결제 수단 · 계좌·카드 · 메모 · 고정 금액을 모두 바꾸고 **[저장]** 을 누릅니다.

- 비워서 저장한 칸(기본 내역 · 결제 수단 · 계좌 · 메모)은 실제로 지워집니다
- 고친 내용은 앞으로 불러올 때부터 쓰입니다. 이 프리셋으로 이미 저장한 거래는 바뀌지 않고, 사용 횟수도 그대로입니다
- **앱에서는 지출 · 수입 프리셋을 이체로 바꿔 저장할 수 없습니다** — "거래 유형(수입/지출)과 카테고리 유형이 맞지 않아요" 가 뜹니다. 웹에서 바꾸거나 이체 프리셋을 새로 만드세요
- 거래 추가 창에서 12자가 넘는 이름으로 저장한 프리셋은, 웹에서는 이름을 12자 이내로 줄여야 저장됩니다(앱은 이름 칸을 건드리지 않으면 그대로 저장됩니다)

## 프리셋 삭제

데스크톱은 행의 **휴지통 아이콘**, 모바일은 행을 밀어서 나오는 **[삭제]** 나 프리셋 상세의 **[삭제]** 를 누르고, 확인 창("○○" 프리셋을 삭제할까요? 이미 저장된 거래 내역에는 영향이 없습니다.)에서 **[삭제]** 를 누릅니다. 모바일 웹에서 행을 밀어 지우면 같은 확인 창이 **한 번 더** 뜨니, 두 번 모두 [삭제]를 눌러야 지워집니다.

:::info[삭제해도 이미 불러와 저장했던 거래에는 영향이 없습니다]
프리셋은 거래를 빠르게 입력하기 위한 "틀"일 뿐 저장한 거래와 이어져 있지 않아서, 삭제해도 그 프리셋으로 이미 저장해둔 거래내역은 그대로 남습니다. 앞으로 그 프리셋을 다시 불러올 수 없게 될 뿐이고, 지운 프리셋의 이름은 새 프리셋에 다시 쓸 수 있습니다.
:::
