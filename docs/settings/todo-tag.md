# 할 일 태그

[할 일](../todo/todo.md)에 붙이는 태그를 만들고 관리합니다. 새로 만든 태그는 할 일을 추가 · 수정할 때 바로 고를 수 있습니다.

![할 일 태그 — 몇 건의 할 일에 쓰이고 있는지 표시됩니다](/img/screens/settings-todo-tags.png)

## 태그 생성

1. **[+ 태그 추가]**
2. **이름**(최대 12자)과 **색상**을 정합니다
3. **[태그 추가]**

![태그 추가 — 이름과 색상만 정하면 됩니다](/img/screens/settings-todo-tag-add-form.png)

## 태그 수정

태그 행을 누르면(오른쪽 화살표) 같은 폼이 열려 이름 · 색상을 바꿀 수 있습니다.

![태그 수정](/img/screens/settings-todo-tag-edit-form.png)

## 태그 삭제

행의 **휴지통 아이콘**을 누르고 확인 창에서 **[삭제]** 를 누릅니다.

![태그 삭제 확인 — 이 태그를 쓰는 할 일은 몇 건인지까지 알려줍니다](/img/screens/settings-todo-tag-delete-confirm.png)

:::danger[삭제하면 그 태그가 붙어있던 할 일은 "태그 없음"이 됩니다]
확인 창이 "이 태그를 쓰는 할 일 N건은 태그 없음으로 남아요"처럼 영향받는 개수까지 미리 알려줍니다. 태그를 삭제해도 **할 일 자체는 지워지지 않고**, 그 할 일들에서 태그만 빠집니다 — [캘린더 라벨 삭제](./calendar.md#라벨-삭제)와 같은 방식입니다.
:::

:::tip[빠르게 추가한 할 일에 태그가 자동으로 붙기도 해요]
할 일 제목에서 내용을 분석해 어울리는 태그를 자동으로 붙여주기도 합니다. 마음에 안 들면 상세 화면에서 바로 바꿀 수 있습니다.
:::
